# 図の選び方（結果の内容 → 図）

**言いたいこと（結果の1文）から図を選ぶ**。データの形から選ばない。1つの図で言うことは1つにする。これは図の万能カタログではなく、このスキルが扱う判断用途を十分に覆う早見表である。関数はすべて `scripts/charts.mjs` にあり、`figure({ title, legend, svg })` で包む。引数の詳細は各関数の JSDoc を見る。

## 1. 早見表

| 言いたいこと（結果の例） | 図 | 関数 | 要点 |
|---|---|---|---|
| どれが大きいか・順位（費目別の増減、地域別の率） | 横棒 | `hbar` | 負の値も可。`threshold` で目標線。`note` で工程の段や補足 |
| 前年と今年など、少数の対比 | 縦棒 | `columns` | 群は6つまで。多いなら `dumbbell` |
| いつから・どれだけ変わったか | 折れ線 | `line` | `baseline` で基準、`compare` で前年 |
| **出来事の前後で変わったか**（制度の施行、感染症、価格の急変） | 折れ線と出来事 | `line`・`multiline` の `events` | 背景の仮説の時期を示す要の図。`at` は点の添字（小数で点の間） |
| 複数の系列が、どう違う動きをしたか（出生と死亡、地域別） | 複数の折れ線 | `multiline` | 5系列まで。名前は線の右端に直接書く |
| 差は何から来たか（分解） | 増減の階段 | `waterfall` | 合計が差に一致すること（`bridge`・`driverTree`） |
| 中身の組み合わせが変わったか（構成） | 積み上げ横棒 | `stacked` | 比率だけを比べるなら `percent: true`。区分は5つまで |
| 項目ごとの2時点の変化（2020→2025 の県別） | ダンベル | `dumbbell` | 悪化の向きを `bad` で指定（既定は減少が悪化）。値の桁がそろう項目で使う |
| 左右の対比（男女・年齢の人口ピラミッド、流入と流出） | 左右の横棒 | `butterfly` | 年齢などの順序の軸を中央に置く |
| 時期 × 層の2軸で、どこが濃いか | ヒートマップ | `heatmap` | 負の値は赤の系統。セルが細いと数字を省く（ツールチップで読む） |
| どう散らばるか、偏っているか | ヒストグラム・箱ひげ | `histogram`・`boxplot` | 箱ひげは群の比較と外れ値 |
| 2つの量は連動するか | 散布図 | `scatter` | r・R²・n を自動で書く |
| 2軸で4つに分類する（量 × 率、距離 × 利益） | 4象限の散布図 | `scatter` の `refs`、`fit: false` | 分類専用。回帰線・r・R²は出さない。基準線は平均・目標など根拠のある値 |
| 差の大きさと不確かさ（効果量と 95% 区間） | 区間の図 | `forest` | 区間が基準（0・1）をまたぐ項目は淡く描く |
| 少数に偏っているか | パレート | `paretoChart` | 上位の累積の割合 |
| **原因候補 → 中間 → 結果の説明仮説の筋** | 図解 | `flow` | 因果の証明ではない。辺は既定で破線。実線は定義・算術・機械的に検証済みの場合だけ `solid` で根拠を指定 |
| 数字をまとめて示す | 統計の要約 | `statStrip` | n・効果量・区間 |
| 項目が多い・正確な値を読ませたい | 表 | `table` | 図に入らない情報の受け皿 |

## 2. 分析の筋ごとの組み合わせ（1要因に図は1〜2つ）

| 筋 | 結論の図 | 要因の図 |
|---|---|---|
| 差の理由（分解 → 背景） | `waterfall` か `flow` | 枝の推移を `line` + `events`、構成なら `stacked` |
| 量 × 率 | `waterfall`（`driverTree`） | 母数と率を `multiline`（単位が違えば図を分ける） |
| 地域・層の違い | `hbar` | 2時点なら `dumbbell`、時期 × 層なら `heatmap` |
| 人口・年齢の構造 | `butterfly` | 世代の節目を `line` + `events` |
| 群の差の検定 | `forest` | `boxplot` |
| 関係・分類 | `scatter` | 4象限の `scatter`（`refs`） |

## 3. 守ること

- 円グラフ・二軸・3D は使わない。単位の違う系列は、1つの図に重ねずに図を分ける。
- 色の意味は固定: 主役 = main、比較 = sub、悪化 = danger、系列 = 1〜5。色だけで意味を伝えず、値やラベルも書く。
- 当てはまる関数が無いときだけ SVG を手で書く（色はクラスで付ける。`references/maintenance.md` の「追加時の判断」）。
- 入力の誤り（範囲外の出来事、区間の外の推定値、右から左への矢印、長すぎる文言）は例外になる。文言を短くするか、データを直す。
