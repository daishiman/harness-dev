# 統計の手引き

表形式の数値データを、記述・比較・関係・分解・推移・集中・異常の7問い型で分析する（記述の型IDは既存の `分布`）。これはこのスキルの判断用途の範囲であり、全統計手法や因果効果推定を網羅しない。関数は `scripts/stats.mjs`、図は `scripts/charts.mjs`。対象外の手法が必要な問いには、無理に答えず限界と次に必要な分析を示す。

## 1. 進め方

1. **問いを型に落とす**（§2）。型が決まれば、手法・関数・図が決まる。
2. **尺度を確かめる**（§3。Stevens）。尺度によって、使える代表値と手法が変わる。
3. **先に探索する**（Tukey の探索的データ解析）。`describe`・`histogram`・`boxplot` で、分布の形・外れ値・欠損・n を見てから検定する。
4. **複数の仮説を競わせる**（Chamberlin の複数作業仮説、Popper の反証可能性）。主な仮説と対立仮説に、計算可能な反証条件を事前に置く。
5. **推定を主、検定を従にする**（§4。ASA 声明 2016、Cohen、Cumming）。
6. **落とし穴を1つずつ点検する**（§5）。
7. **図にする**（§6。Cleveland & McGill、Tufte）。

## 2. 問いの型 → 手法 → 関数 → 図

| 型 | 問いの例 | 手法 | 関数 | 図 |
|---|---|---|---|---|
| 分布 | どう散らばるか、偏っているか | 要約統計量（中央値と IQR、平均と SD）、平均の区間 | `describe` `meanCI` | `histogram` `boxplot` |
| 比較 | 群や期間で違うか | 量: Welch の t と Cohen の d。順位: Mann-Whitney と r。比率: Wilson の区間、分割表の χ² と Cramér の V | `welch` `mannWhitney` `rateCI` `chisq` | `hbar` `boxplot` `columns` |
| 関係 | 2つの量は連動するか | 直線: Pearson の r。単調・外れ値あり: Spearman の ρ。傾き: 単回帰と R²。カテゴリ同士: χ² | `pearson` `spearman` `linreg` `chisq` | `scatter` |
| 分解 | 差は何から来たか | 足し算の指標は項目別の差。掛け算の指標は LMDI（Ang）。どちらも合計が差に一致する | `bridge` `driverTree` | `waterfall` |
| 推移 | いつから、どれだけ変わったか | 基準期間の平均 ± 2SD から外れた点（Shewhart の管理図の考え方）。時間に対する線形の傾き | `describe` `linreg` | `line` |
| 集中 | 少数に偏っているか | パレート分析（Juran）と ABC 区分 | `pareto` | `paretoChart` |
| 異常 | 例外はどれか | Tukey の 1.5 IQR の柵 | `outliersIQR` | `boxplot` |

- 同じ対象の前と後を比べるときは、間隔・比率尺度に限り、対ごとの差の配列に `meanCI` を使う。区間が0をまたぐかで判断する。対応のある順序尺度の差は対象外とし、限界と次の分析に送る。
- 3群以上の比較では、対ごとに比べて `holm` で補正する。比率なら `chisq` で一度に比べる。
- 表示の言葉は Cohen の d に `effectLabel(d)`、Pearson/Spearman の相関に `corrLabel(r)`、Mann-Whitney の順位効果に `rankEffectLabel(r)`、p 値に `pText(p)` を使う。`corrLabel` を順位効果 r に流用しない。
- 図の列は型ごとの基本形。結果の内容（出来事の前後・構成・2時点・区間・説明の筋など）に合わせた図は `references/charts.md` で選ぶ。

## 3. 尺度（Stevens）

| 尺度 | 例 | 代表値 | 使える手法 |
|---|---|---|---|
| 名義 | 種別、地域、はい/いいえ | 最頻値、比率 | `rateCI` `chisq` |
| 順序 | 5段階評価、順位 | 中央値、分位 | `spearman` `mannWhitney` |
| 間隔・比率 | 金額、時間、距離、件数 | 平均と中央値 | すべて |

- 比率（%）には分母 `k/n` を添える。
- 率を平均しない。「合計 ÷ 合計」で計算する（分母で重み付けされる）。

## 4. 推定と検定の規則

- **効果量を先に書く**。目安は次のとおり。
  - Cohen の d: 0.2 小、0.5 中、0.8 大
  - Mann-Whitney の順位効果 r: 0.1 小、0.3 中、0.5 大
  - Cramér の V（2×2）: 0.1 小、0.3 中、0.5 大
  - 目安は分野で変わる。現場の単位での差（円、分、件）も必ず併記する。
- **95% 区間を添える**。区間が0を含むときは「差があるとは言えない」と書く。「差が無い」とは書かない（Altman & Bland: 証拠が無いことは、無いことの証拠ではない）。
- **p 値は従にする**。p 値は、効果の大きさも重要さも示さない（ASA 2016）。p < 0.05 だけで結論を決めない。
- 2群の平均の比較は、等分散を仮定しない Welch を既定にする。外れ値がある、歪みが強い、順序尺度である、n が小さい、のいずれかなら `mannWhitney` も計算する。2つで結論が変わるなら判定を「保留」にする。
- **独立性**。同じ対象を繰り返し測った値を、独立な n として数えない（Hurlbert の擬似反復）。対象ごとに集計してから比べる。
- **標本推論**。区間や p 値は、独立な観測単位が対象を代表する標本とみなせるときだけ使う。全数・便宜抽出・選択の偏りがある場合は観測範囲の記述にとどめる。
- **欠測と n**。欠測は自動補完せず、項目ごとに除外数・欠測率と実際の n を示す。n は行数ではなく、その比較の独立な観測単位で数える。
- **多重比較**。検定を複数したら、`holm` の調整 p 値で判断する。探索中に見つけた差は「仮説の候補」と書き、確かめた結果のようには書かない。
- `chisq` の `lowExpected` が true なら、カテゴリをまとめるか、判定を保留にする。
- 相関・回帰は x / y のどちらかがゼロ分散なら定義できない。Welch は両群ともゼロ分散、または標準誤差 / プール標準偏差が0・非有限なら定義できない。これらの場合は `pearson` `linreg` `welch` を例外にし、`0`や`p=1`と表示せず「算出不可」と保留する。Welch は片群だけがゼロ分散でも、他群に分散があり各統計量が有限なら算出できる。
- n < 10 は検定の結論を断定しない。「傾向」と書く（検査の W05）。

## 5. 落とし穴（判定の前に点検する）

| 落とし穴 | 点検すること |
|---|---|
| Simpson のパラドックス | 層（区分・群）で分けると、差の向きが逆にならないか |
| 交絡（相関は因果ではない） | 両方に効く第3の変数がないか。時間の前後・量反応・一貫性・機序を点検しても因果の証明にはならない。レポートでは「関連」「説明と整合」と書く |
| 平均への回帰 | 極端な値の対象だけを選んで次の期間を見ると、何もしなくても平均に近づく。前後の比較には、対照となる群を置く |
| 選択・生存バイアス | データに入らなかった対象（途中で消えた、回答しなかった）が結論を変えないか |
| 生態学的誤謬 | 集計単位の関係を、個々の対象に当てはめていないか |
| 基準率の無視 | 件数の比較を、母数で割って率にしたか |
| 小さい n | 極端な値は小さい群から出やすい（Wainer）。順位やランキングを n と一緒に示す |
| 外れ値 | 黙って除いていないか。除く前と除いた後の両方を示す |

## 6. 図（Cleveland & McGill、Tufte）

- 位置は、長さより正確に読める。長さは、角度・面積より正確に読める。円グラフ、3D、二軸は使わない。
- 棒は0から描く。折れ線は0から始めなくてよい。
- 1つの図で1つのことを言う。比べるものは、同じ軸に並べる。
- 値は、凡例ではなく棒や点の近くに書く。飾り（データを表さないインク）を足さない。

## 7. 扱わない範囲

予測は、`linreg` による線形の傾向までにする。次の手法はこのスキルでは扱わない。

- 季節性や時系列のモデル
- 重回帰と機械学習
- 因果推論の手法（傾向スコアなど）
- ベイズ推定
- 生存分析
- 必要な標本の大きさの設計

問いにこれらが必要なときは、「このスキルでは扱わない」と `caution` に書き、ユーザーに伝える。
