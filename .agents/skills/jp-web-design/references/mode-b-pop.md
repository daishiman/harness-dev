# モードB「Pop・親しみ」(catnoseプロダクト群の実測・発信から汎用化)

モードBを選んだときの全ルール。nani.nowの実測と、catnoseの発信(「**誰でも入りやすいカラーは淡い青**」「白とグレーだけと決めて配色」「**10秒かかる作業を2秒にする**」「UIから作り、自分が最初のユーザー」「機能は最小限・不要な機能は負債」)を咀嚼したtoC向けモード。**変わるのは「色のトーン・面・丸み・太さ・かわいさ」。組版禁則・数値・アクセシビリティ・UX規律は平賀カラー(既定)と完全共通。**

## 1. カラー: パステル変換(Popの心臓部)

**Popモードでは指定されたプライマリカラーをそのまま使わず、パステル(淡色)トーンに変換する。**濃紺・原色をPopに持ち込むと途端に硬くなる。

| 指定 | Pop用パステル(面・CTA) | 文字・リンク用のdeep |
|---|---|---|
| 青・水色 | 淡いスカイ `#8ecdf8` | `#2273b8` |
| 赤 | コーラル `#ffa8a0` | `#c2504a` |
| 緑 | ミント `#9adbb4` | `#2e8f5b` |
| 紫 | ラベンダー `#c3b8f0` | `#6b5bb8` |
| ピンク | ベビーピンク `#f9b8cf` | `#c2537e` |
| 黄・オレンジ | アプリコット `#ffcf9e` | `#c07a2e` |

- 変換ルール: **明度を上げ、彩度は中庸に残す**(白っぽすぎると病院、鮮やかすぎると玩具)。
- **主要CTAは「明るいブライト色+白太字+同色相の淡いリング」**(Nani実測: スカイブルーのピル+白文字+外側に淡水色の縁)。リングは `box-shadow: 0 0 0 5px <soft色>`。ブライト色はパステルより一段鮮やかでよいが原色にはしない。
- **プライマリが背景の要素は白文字・白グリフ**(CTA・チェックON・トグルON)。黒いチェックマークは禁止。ネイティブ `accent-color` は明るいプライマリだと**黒チェックを描いてしまう**ため、チェックボックスは自前描画で白チェックにする:

```css
input[type="checkbox"].pop-check {
  appearance: none; width: 22px; height: 22px; border-radius: 7px;
  border: 2px solid #c9dff5; background: #fff; cursor: pointer;
  display: grid; place-items: center;
}
input[type="checkbox"].pop-check:checked { background: var(--pop-primary); border-color: var(--pop-primary); }
input[type="checkbox"].pop-check:checked::after {
  content: ""; width: 11px; height: 6px; border-radius: 1px;
  border-left: 3px solid #fff; border-bottom: 3px solid #fff;
  transform: rotate(-45deg) translate(0, -2px);
}
```

- チェックボックス・トグル等のコントロールのON色は**ブライト**(deepの濃紺を使わない — 1箇所だけ濃いと浮く)。
- deep側は文字・リンク・線画アイコンにだけ使う(面に使わない)。
- 差し色1・accent2箇所・色相3つの規律は不変。

```css
:root[data-mode="pop"] {
  --pop-primary: #43a4f5;      /* ブライト(CTA・トグルON・強調) */
  --pop-primary-pastel: #8ecdf8; /* パステル(マスコット・面) */
  --pop-primary-soft: #d9edfe; /* 選択状態・チップ・CTAのリング */
  --pop-primary-deep: #2273b8; /* 文字・リンク・アイコン */
  --pop-bg: #eaf5fe;           /* ページ地(プライマリ色相の淡色) */
  --pop-card-radius: 24px;     /* カードは罫線なし+大きな角丸(実測27px) */
  --pop-control-radius: 12px;  /* チップ・入力。主要CTAはピル(999px) */
}
html[data-mode="pop"] body { font-size: 16px; } /* 実測16.7px。ゆとり=親しみ */
```

## 2. 「これをすればいいんだ」の構造(分かりやすさが最優先)

Popの本質は丸さではなく**迷いゼロ**。catnoseの「10秒の作業を2秒に」を構造で実現する:

1. **1画面1アクション**: ファーストビュー=一言キャッチ+主役カード+CTA1つ、の縦一直線。並列の選択肢をファーストビューに置かない。
2. **開いた瞬間に価値**: ログイン・設定・説明より先に、触れる主役を置く(Naniは開いた瞬間に入力欄)。試すまでの障壁を最下限に。
3. **最頻タスクの手数を数える**: 主役タスクが2〜3操作で完了するか。しないなら機能を削るか、デフォルトで先回りする。
4. 説明文で埋めない: 機能は「ストロークアイコン+体言止め1行」。placeholderとマイクロコピーが挙動を語る。
5. 選択は**チップのぽちぽち**(自由入力より選択)。等幅グリッド・太字・選択状態は `--pop-primary-soft`。

## 3. かわいらしさの作り方(Nani実測ディテール・幼くならない範囲で)

| 要素 | 作法 |
|---|---|
| マスコット | **必ず本スキルの `assets/pop-mascot-editable.svg` を使う(自作しない)**。使い方は下記「マスコットの使用ルール」 |
| 見出しの遊び | ヒーロー見出し・ロゴは**黒太字+わずかな傾き**(rotate -1〜-2°、ロゴならitalic)。セクション見出しには**波線の下線**(`text-decoration: underline wavy` をsoft色・offset 6px)。どちらも主役級の見出しだけに |
| 手書き注釈 | **くるっとループする矢印**+短い一言(「ログインなしで試せます」)。注釈ごと1〜2°傾けると手書き感が出る。矢印は下の検証済みSVGを使う(ぐちゃぐちゃな自作曲線にしない) |
| 機能カード | **破線ボーダー**(2px dashed soft色)+太字タイトル+1行説明。ありがちなメタファーアイコン(書類・グラフ)は置かない。**アイコンなしが基本形** |
| コントロール | セグメント切替(淡グレーのトラックに**白ピルが浮く**)/トグルスイッチ(ON=ブライト色)。**設定・調整ボタンはプライマリの枠線で際立たせる**(どこを触れば調整できるかを迷わせない) |
| 角と影 | 全要素大きめ角丸。影はごく淡く低く(色地が浮かせるので基本不要) |
| 文字 | 操作要素も太字700。マイクロコピーは口語OK(「ぽんと送る」)。ただし1文は短く |
| 遊びの上限 | 傾き・波線・ループ矢印・マスコットの顔 — **1画面2〜3つまで**。絵文字は不可 |
| 完了画面 | ピークエンド: マスコット+ひとこと+次の1歩。かわいさの出しどころはここ |

- Enter送信は既定OFFのまま、**設定トグル「Enterキーで送信」として提供してよい**(Nani踏襲。サブラベルに「Shift+Enterで改行」を添える)。既定の送信は⌘/Ctrl+Enter+ボタン(`motion-a11y.md` 操作感の基準)。
- くるっと矢印(検証済み・deep色/2.4px/丸端。矢先は下右向き)。**サイズは26px前後の控えめに**、注釈テキストの中央に置く(viewBoxは描画にぴったり合わせてあるので中央揃えでズレない。拡大して使うとループが主張しすぎる):

```html
<svg width="26" height="26" viewBox="0 0 26 26" fill="none" aria-hidden="true">
  <path d="M16 4.2 a4.2 4.2 0 1 0 -1.5 8.1 C 13.2 15.6 14.6 19.2 18.4 21.6"
        stroke="var(--pop-primary-deep)" stroke-width="2.4" stroke-linecap="round" fill="none"/>
  <path d="M14.4 21.4 L 18.9 22 L 18.1 17.7"
        stroke="var(--pop-primary-deep)" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round" fill="none"/>
</svg>
```

## 4. マスコットの使用ルール(`assets/pop-mascot-editable.svg`)

発注者承認済みのキャラクターアイコン原本。**Popモードのマスコットはこれ一択**(CSSで顔を自作しない・別の絵を描かない)。

- **色替えはコードで行う**: SVG内の `:root` CSS変数を差し替えるだけで再着色できる。
  - `--body-light / --body-main / --body-dark` → **プライマリのブライト3トーン**(main=ブライト、lightは+8%明るく、darkは-8%暗く)
  - `--border-light / --border-mid / --border-dark` → **soft側の淡色3トーン**(リング)
  - 瞳(`--pupil-*`)・白目・ハイライトは**どのブランドでも変えない**
- **2バージョンを使い分ける**:
  - **縁ありバージョン**(原本のまま) — ヒーロー・空状態・完了画面・アプリアイコン/faviconなど「主役として置く」場所
  - **縁なしバージョン**(`#outer-frame` の rect を削除し、viewBoxを本体に合わせてクロップ) — ヘッダーロゴ・フッター・リスト内など「小さく添える」場所。小サイズで縁があると潰れる
- プロジェクトには `mascot-bordered.svg` / `mascot-borderless.svg` の2ファイルとして複製し、`<img>` で使う(サイズは width/height 属性で指定)。
- 表情・目の位置の改変はしない。動かすのは完了画面の一拍(pop-in)だけ。

## 5. Popでも不変の規律(親しみと引き換えにしないもの)

- **視覚的主役は1画面1つ**。丸く・太くしても、全部を目立たせれば視線誘導は死ぬ。
- 数値・単位・カンマの規律、「濃く太い数字=変わる値」の文法、フォーカス可視化・タップ44px、Enter送信の規律とキーキャップ表示はそのまま。
- 黒背景・黒CTAの禁止、reduced-motion対応も不変。バウンスは使わない。

## 6. 使い分けの目安

- **B(Pop)を選ぶ**(明示指定時のみ): 一般消費者向けツール・学習/翻訳/日常系・若年層・「気軽に触ってほしい」が要件のとき。
- **平賀カラー(既定)を使う**: 業務・金融・医療・報告/管理系・「間違えないこと」が最優先のとき。
- Popは利用者が明示指定した場合だけ使う。迷ったら平賀カラー(`hiraga-color-system.md`)。「明るくしたい」程度の動機でPopへ切り替えない。
