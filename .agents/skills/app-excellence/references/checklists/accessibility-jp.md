# Checklist: アクセシビリティ+日本市場適合(WCAG 2.2 AA相当)

## 知覚(★=Sサイズでも必須)

- [ ] ★ テキストコントラスト 4.5:1 以上(大文字は3:1)/UI部品は3:1以上
- [ ] ★ 色だけで意味を伝えない(エラーは色+アイコン+文言)
- [ ] ★ 文字を200%に拡大しても操作・閲覧が破綻しない
- [ ] 全ての意味のある画像に代替テキスト(装飾画像は空alt)

## 操作

- [ ] ★ キーボードのみで全ジャーニーが完了できる/フォーカスが見える
- [ ] ★ フォーム全項目にラベルが紐づく(placeholderをラベル代わりにしない)
- [ ] タップ領域最小24px(推奨44px)・要素間に十分な間隔(WCAG 2.2 Target Size)
- [ ] 時間制限のある操作に延長手段がある/自動再生・点滅なし

## 理解(日本語)

- [ ] ★ 敬体で統一・専門用語ゼロ・カタカナ略語に頼らない
- [ ] ★ エラー文は「何が起きた/データは無事か/次に何をする」の3点構成
- [ ] 日付は和暦/西暦の文脈整合・全角半角の自動正規化(ユーザーに直させない)
- [ ] 氏名は姓名分割を強制しない・外字/長い名前/ミドルネームで壊れない
- [ ] 電話番号・郵便番号はハイフン有無どちらでも受ける/住所は郵便番号から補完

## 日本のモバイル現実

- [ ] 375px幅(iPhone SE級)で全画面が成立する
- [ ] 通勤圏の低速回線で使える(performance.mdと連動)
- [ ] OSの文字サイズ設定(大)に追従する
