# Checklist: パフォーマンス予算(体感=UXの土台)

計測条件: 本番相当のプレビュー・キャッシュなし初回訪問・中位スマホ+3G/4G相当スロットリング。

## Core(★=Sサイズでも必須)

- [ ] ★ LCP < 2.5s(主要3画面)
- [ ] ★ INP < 200ms(主要操作)
- [ ] ★ CLS < 0.1(画像・埋め込みに寸法指定/挿入コンテンツで押し下げない)
- [ ] ★ 初期JSバンドル < 200KB gzip(超過時はdynamic importで分割)
- [ ] API応答 p95 < 300ms(集計等の重い処理は非同期化+進捗表示)

## 体感速度

- [ ] ★ 0.4秒超の待ちにスケルトンor進捗(白画面・無反応の時間ゼロ)
- [ ] 楽観的UIが保存系操作に適用されている
- [ ] 次に高確率で使う画面・データの先読み(prefetch)
- [ ] 画像: 最適化コンポーネント経由・遅延読み込み・適切なsizes

## データ・インフラ

- [ ] N+1なし(主要クエリのEXPLAIN確認)/10msを超えるクエリにインデックス検討
- [ ] 静的化・キャッシュできるものがされている(ISR/CDN)
- [ ] 大容量メディアはR2等へオフロード(帯域コスト=性能予算の隣にあるコスト予算)
- [ ] リリース後の実測手段がある(Vercel Analytics等で本番RUMを確認する日が決まっている)
