4Cowork に慣れる15分

同じアプリの中でCoworkを開き、まとめて任せられる感覚を体験します。

フォルダごと任せられる
中のファイルを自分で探して読み、書き込み・整理までやる
時間で勝手に動く
毎週・毎月の繰り返しをスケジュール実行で自動化
操作を録画して覚える
普段のPC操作を見せると、スキルとして覚えて次から自動でやる

向いている作業／向いていない作業

Cowork に向いている
  • フォルダごと・複数ファイルをまとめて扱う
  • 集計→グラフ化→資料化まで通しでやる
  • 毎週・毎月の繰り返し、時間のかかる作業
  • 手作業をスキル録画して自動化したいもの
  • 連携アプリからの情報収集・まとめ
Cowork に向いていない
  • 一往復で終わる短い質問・調べもの
  • 目線や判断基準が決まっていない壁打ち
  • やりとりしながら方向を変えたい作業
  • 入力データが手元にない・整っていない依頼
  • コードを書いて動かす開発（Claude Code）

基本の型

まず チャットで
作戦会議（壁打ち）
きまったら Coworkに
丸ごとおまかせ

実際にやってみる

1. チャットで決めた手順を、そのままCoworkに丸ごと任せる

分析の目線をチャットで固めてから、そのまま渡すのが基本です。

車両別収支計算用2026年5月.xlsx1.2MB

ボタンで保存できない場合は、この資料を埋め込んでいるNotionページ内の添付ファイルから取得してください。

車両別・軌道別の推移と赤字要因をまとめて、報告用のExcelと要約資料にしてください。
2. フォルダをまとめて整理させる

必要項目の抜き出し、一覧表化、ファイル名の統一まで一度に頼めます。展開してフォルダごと渡してください。

車両収支データ.zip1.4MB

ボタンで保存できない場合は、この資料を埋め込んでいるNotionページ内の添付ファイルから取得してください。

このフォルダ内のファイルを全て読み取り、以下をやってください。

1. 各ファイルから「日付・車両番号・売上・経費」を抜き出して1つの一覧表にする
2. 車両別・月別に集計し、赤字車両を特定する
3. 報告用のExcel（集計表＋グラフ）と、要約のパワポ2枚を作る
4. 成果物は「/output/2026-08」フォルダに保存し、ファイル名は「YYYYMM_内容」で統一

不明点や表記ゆれがあれば、勝手に判断せず一覧にして報告してください。
3. 定型資料の作成をスケジュール実行で任せる

毎月同じ形式のレポートは、時間を決めて自動で作らせます。

毎月1日の9:00に、前月分の実績レポートを自動作成してください。

- 入力：/data フォルダ内の前月分データ
- 出力：報告用Excelとパワポ（前月と同じ体裁を踏襲）
- 完了したら、変化が大きかった点を3行で要約して知らせてください

コツ：「何を・どうやって・どんな形で出すか」を最初に伝える。進めてもらっている間は、他の作業をしていてOK。

5チャットとCowork、共通のしくみ3分

どちらで覚えても、両方で使えます。

コネクタ ＝ 外とつながる
Notion・Kintone・カレンダーなどと接続。Claudeがアプリ同士をつなぐハブになる
スキル ＝ やり方を覚える
仕事の手順・型をClaudeに覚えさせて、何度でも使い回す。操作の録画から覚えさせることもできる

くわしい設定は1回目の研修であつかいます。
