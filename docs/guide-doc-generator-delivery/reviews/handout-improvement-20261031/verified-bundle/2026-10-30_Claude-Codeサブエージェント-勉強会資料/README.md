## 目的

作業を一つの会話に頼み続けると机が埋まります。この回では、作業をサブエージェントに分けて任せる形へ移ります。最初からいるサブエージェントに調べものを任せ、自分のサブエージェントを作って呼び出すところまで進めます。

資料の中心は「サブエージェントは別の机で作業し、メインには結果だけを返す」ことです。もう一つ、「机は別でも、使用量は同じ財布から出る」ことも扱います。たくさん読む調べものはサブエージェントへ任せ、小さな頼みはそのまま頼みます。

表紙のすぐ後に Hyogo AI vol.1（2026年12月6日）の案内を置き、運営連絡の付録に詳しい版を置いています。

## 各同梱物の使い方

### handout.html

ブラウザで開く配布資料です。画像・スタイル・図を内部に持ち、このファイル1つで共有できます。13節を維持しています。ファイルサイズは33,116,755バイトです。

受け渡しはシーケンス図、3件の同時処理は分岐・合流図、スキルの組合せは関係図で表現しています。呼び方・得失・選び分けはHTMLの比較表やカードで表示し、同じ内容を図と文章で繰り返さないよう整理しました。

SVG内の文字は実表示14px以上を保ち、狭い画面では図の中を横スクロールします。「図を拡大」はキーボードでも開閉できます。実習は「操作・成功の目安・つまずいたら」を区別し、スマートフォン幅では縦に並びます。補足は開閉でき、印刷時は展開し、終了後に元の開閉状態へ戻ります。

メモ欄に書いた内容は、操作帯の「メモを埋め込んだ HTML を保存する」から持ち出せます。

### handout-config.json

資料の中身を直すときは、ここから直します。本文・表・図解・節の並びはすべてこの JSON にあります。HTML を直接編集せず、この JSON を直してから、下のコマンドで作り直してください。配布版の再現単位は、この正規化済みJSONと同梱素材です。HTMLだけからの逆抽出は補助経路であり、画像計画などのメタデータには比較差分が残ります。元のJSONを保持してください。

### assets/images/

挿絵と QR の原本です。話し手のQRは、原画像を無加工で内包する `qr-speaker-links-readable.svg` で表示幅860pxに整えています。元の `qr-speaker-links.png` も保持しています。`handout.html` に data URI として埋め込んであるので、配布するときにこのフォルダを一緒に渡す必要はありません。差し替えるときは、ここに同じ名前で置いてから作り直してください。

### assets/prompts/

挿絵を作り直すときに使います。どの絵も同じ画風の指定（アイソメのジオラマ・人物なし・絵の中に短い日本語の札を描く）で始まり、その後に1枚ごとの場面が続きます。

### assets/qr/

構成案の段階で作った QR の原本です。4回目までの資料では、このうち6本（Hyogo AI vol.1 と AI質問会を除く）を1枚にまとめた `assets/images/qr-speaker-links.svg` を使っていました。5回目からは、話し手の6つのリンクを1枚にまとめた `assets/images/qr-speaker-links.png` に差し替えていて、このフォルダの6本は使っていません。Hyogo AI vol.1 の QR は、帯用と付録用で大きさを変えて `assets/images/` に作り直しています。11月14日の AI質問会の QR（`qr-ai-shitsumonkai-1114.svg`）は、Hyogo AI vol.1 の帯用と同じ大きさで `assets/images/qr-1114-140.svg` に作り直しています。

## 再生成コマンド

更新したローカルプラグインを使います。古いキャッシュ版では今回の図や表示を再現できません。配布版の構成データは正規化済みなので、再現確認では値を書き換えずに使用します。

```bash
HB_SCRIPTS="/Users/dm/dev/dev/個人開発/harness/plugins/guide-doc-generator/scripts"
HB_DOCUMENT="/Users/dm/dev/dev/ObsidianMemo/05_Project/説明資料/2026-10-30_Claude-Codeサブエージェント-勉強会資料"
HB_BUILD=$(mktemp -d)
python3 "$HB_SCRIPTS/validate-handout-config.py" --config "$HB_DOCUMENT/handout-config.json"
python3 "$HB_SCRIPTS/embed-assets.py" --config "$HB_DOCUMENT/handout-config.json" --assets-dir "$HB_DOCUMENT" --out "$HB_BUILD/embedded.json"
python3 "$HB_SCRIPTS/render-handout.py" --config "$HB_BUILD/embedded.json" --out "$HB_BUILD/handout.html"
cmp "$HB_DOCUMENT/handout.html" "$HB_BUILD/handout.html"
```

変更せず実行すると、HTMLのバイト一致を確認できます。内容を改訂するときは構成データを編集し、C12で別ファイルへ正規化し直してから生成します。選定証跡も改訂後の構成データへ更新してください。

警告は節数（13節）と埋め込みサイズの報告です。静的検査4面の不合格とは区別しています。
