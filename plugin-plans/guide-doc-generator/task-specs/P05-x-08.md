> C11 のトークン間接参照テストは _accent_key がトークンファイルのトップレベルキーに pop-primary を含むものを探すが、assets/tokens/pop.json のトップレベルは schema_owner / produced_by / theme / label / is_default / source / accent / css_variables でありアクセント色は 2 階層下にある。当該ファイルの produced_by は P05-x-02 だが同 leaf は既に done であり受け皿が無い

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
