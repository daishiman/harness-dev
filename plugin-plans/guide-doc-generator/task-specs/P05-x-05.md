`P04-x-05` の裁定 G-04 (`assets/`)、`P05-x-03` (`config/`) と**同一の欠陥クラスの 3 例目**に対応する build leaf。`plugins/guide-doc-generator/schemas/handout-config.schema.json` は `component-inventory.json` と 4 本のブリーフ (C12 / C05 / C14 / C23)、および 4 箇所のテスト (`tests/validate-handout-config.py/_harness.py` / `tests/handout-content-architect/contract_lib.py` および同 fixtures / `tests/resolve-handout-preset.py/_harness.py`) から参照されているが、`plugin-plans/guide-doc-generator/task-specs/*.md` のどの `produces` にも `write_scope` にも現れず producer が存在しなかった。`validate-task-graph.py` の規則 (c) は「1 成果物の producer は 1 つまで」であり **0 個を検出しない**ため、同じ経路で漏れた。

## canon authority と write authority の分離 (`P05-x-03` と同じ形)

スキーマ語彙の canon authority は C12 にある (`script-brief-C12.json` の `config_schema`)。本 leaf が引き受けるのは write authority のみで、`write_scope` が非空 string 1 本しか取れない仕様上、`scripts/validate-handout-config.py` を持つ C12 の build leaf が同時に `schemas/` を持つことは構造上できない。

逆向きの禁止: **C12 / C05 / C14 / C23 の build leaf は `schemas/` へ 1 バイトも書かない。**

## 産出内容

`schemas/handout-config.schema.json`。`script-brief-C12.json` の `config_schema` を正本とし、スキーマの語彙を本 leaf で新たに発明しない。ブリーフに記述が無い項目が必要になったら、勝手に決めず完了報告の `brief-underspecified` に列挙する。

少なくとも次の 3 系統を宣言する:

1. **構造**: セクション / 部品 (`config/handout-parts.json` の part id 語彙と整合) / 画像・図解ノード。
2. **R22 の粒度 enum**: `detail_level` = `overview` / `standard` / `detailed`、`evidence_depth` = `none` / `cited` / `sourced`。**この enum が値域の唯一の正本**であり、`resolve-handout-preset.py` はここから動的に値域を得る (script 側への値リテラル記述は `AC-C23-R22-61d` と `NoRuntimeFallbackTest.test_script_has_no_default_value_literals` が禁じている)。
3. **R21 の必須文書フィールド**: `must_remember` / `no_need_to_remember` を含む、`config/handout-purposes.json` の `required_document_fields` が参照するフィールド群を `properties` のキーとして持つ。`E-PRESET-REQFIELD-UNKNOWN` の照合表がこの `properties` キー集合である。

## 緑にすべき既存の赤 (二値の受入基準)

本 leaf の完了時に次の 3 件が緑になること。これらは `P05-C23-01` がスキーマ不在のために緑にできなかった残存赤である:

- `tests/resolve-handout-preset.py/test_lecture_preset.py::LectureRequiredDocumentFieldsTest::test_declared_fields_exist_in_config_schema`
- `tests/resolve-handout-preset.py/test_lecture_preset.py::RequiredDocumentFieldsValidationTest::test_unknown_document_field_is_rejected`
- `tests/resolve-handout-preset.py/test_r22_granularity_defaults.py::GranularityCatalogGateTest::test_out_of_range_value_is_exit1`

同時に、**既に緑の 125 件を 1 件も赤にしないこと**。特に `test_single_field_of_the_pair_is_not_rejected_by_c23` は「スキーマ不在の fixture root でも exit 0」を固定しており、スキーマの存在によってこの経路が壊れてはならない。

## 禁止事項

- `plugins/guide-doc-generator/tests/` を変更しない。緑にならないならスキーマを直す。
- `plugins/guide-doc-generator/scripts/` を変更しない (`P05-C23-01` の成果物は確定済み)。
- `config/` の値を複製しない。スキーマは形を宣言し、値は `config/` が持つ。
- 外部 URL (`$schema` の draft URL を含む) を書かない。R01 の自己完結性は生成物だけでなくプラグイン同梱データにも適用する。スキーマ方言を示す必要があるなら URL でない識別子を使う。
