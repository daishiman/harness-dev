`P13-x-02` / `P13-x-03` の成果が実際に install 可能性へ到達しているかを測る leaf。

## 測る対象

| 経路 | 機械実測できること | 実測できないこと |
|---|---|---|
| ローカル (`harness-local`) | `build-local-marketplace.py --check` exit0、生成 `marketplace.json` の `plugins[]` に entry と `source: ./plugins/guide-doc-generator` があること | Claude Code の `/plugins → Add Marketplace` 操作そのもの |
| GitHub (`skills`) | `validate-plugin-completeness.py` exit0、`.claude-plugin/marketplace.json` への登録、`lint-readme-plugin-root-portability.py` exit0 | PR merge 後の remote からの取得 (未 push のため) |

## 進め方

0. **実測に使う登録手段。** `plugins/harness-creator/commands/marketplace-register.md` (本 plan の外にあり producer を持たないため `consumes` には置かない) を使って掲載を確かめる。
1. **未実測を pass と書かないこと。** 対話 UI 操作と remote 取得は本 leaf の到達範囲外であり、`not-run` として理由付きで残す。ここを推定 pass にすると TG-C08 の completion evidence が Goodhart 緑化する。
2. `source` の形式制約を明示的に確かめる: `./plugins/guide-doc-generator` であり `../` を含まないこと (`source: Invalid input` の既知の踏み抜き)。
3. version 据置きのまま中身を直しても install は取り直されない性質 (install は copy) を証跡へ注記し、更新手順として `build-plugin-release.py --install` を残す。
4. 記録先は `plugin-plans/guide-doc-generator/evidence/P13-distribution.json`。`P13-x-01` の判断記録はこの実測を参照する。
