`P04-x-07` の裁定 (c) に対応する build leaf。SRG 同梱の `style-genome-kanagawa-comic-diagram.json` はアイソメ 1 系統しか持たないため、参考画像のフラット正面図系に正本が無い。本 leaf がその producer になる。

## write_scope の境界 (`P05-x-02` との切り分け)

`plugins/guide-doc-generator/assets/` の唯一の producer は `P05-x-02` である。genome は `assets/` の下に置かず **`plugins/guide-doc-generator/genomes/` を独立したトップレベルとする**。理由: `assets/` 配下へ入れると producer が 2 leaf になり、`P04-x-05` の裁定 G-04 で閉じた「1 成果物 1 producer」を自ら崩す。genome は Web 資産ではなく画像生成の画風正本なので、別ディレクトリであることは意味的にも正しい。

## 産出内容

`genomes/style-genome-flat-infographic-jp.json`。`build-image-prompts.js` が `--genome <path>` で読むため、**SRG 同梱 genome と同じ schemaVersion・同じトップレベルキー集合**を持たせる (キーを増減させると読み側の互換が壊れる)。

参考画像 2 枚から起こす画風仕様:

- **投影**: フラット正面図 (アイソメではない)。奥行き表現は薄い影とカード枠のみ。
- **地色**: クリーム (#FDF6E3 近傍)。参考画像の背景がこれ。
- **支配色**: 濃緑 (#1E4620 近傍)。見出し帯・アイコン・矢印・円形フォーカスに使う。
- **アクセント**: 橙 (#E8722C 近傍)。数値と「削減」等の強調語だけに使う。60-30-10 の 10 側。
- **構図型**: (1) 対比 2 枚 (導入前 / 導入後) を左右のカード枠に置き中央に円形の結果指標を置く型 (2) 3 要素が中央へ収束する型 (3) 上部に大見出し・下部に 1 行の結論帯を置く共通枠。
- **数値強調**: 数値を最大級の字面で焼き、単位を小さく添える (「約**94**%削減」「約**8**時間」→「約**30**分」)。
- **モチーフ語彙**: ノート PC / モニタ / スマートフォン / チェックリスト / 人物 (簡略・顔の描き込みなし) / AI ロボット / 盾 / 本 / 循環矢印 / 簡易バー (量の比較) / 円形フォーカス。
- **textPolicy**: `baked-with-overlay` を持つ (裁定 (a))。参考画像は見出し・ラベル・キャプションをすべて焼き込んでいる。
- **negativePrompt**: 写実・3D レンダ・暗背景・高彩度・崩れた日本語・小さすぎて読めないラベル・絵文字風ピクトグラム・平坦な単色ボックスだけの図。

## 禁止事項

- SRG 同梱 genome をコピーして差分編集した痕跡 (同一の説明文の丸写し) を残さない。参照はしてよいが、キー構造の互換だけを合わせ、内容は参考画像から起こす。
- 色の実値を C11 のテーマトークン (`P05-x-02` の `assets/tokens/`) と共有しない。あちらは HTML の配色、こちらは生成画像の配色で、正本が別である (混ぜると `P05-C04-01` で記録した `canon-duplication-risk` を再発させる)。
- 画像生成のロジックを書かない。本 leaf は宣言データ 1 本を置くだけ。
