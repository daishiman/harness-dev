`P05-C20-01` が build 中に発見したタスク。発見理由は次のとおり。

> AC-C20-02 (復元した構成データを C11 で再レンダリングしてバイト一致) が現契約では原理的に成立しない。完全マーカー付き HTML から復元しても focus_theme / target_tasks / attainment_level / must_remember / no_need_to_remember / ties_to は C11 の renderer_marker_requirements に対応マーカーが無く HTML へ刻まれていないため復元不能。加えて notes_enabled(null) の型・date の表示書式・assets[].data_uri が C12 schema の additionalProperties:false に抵触する。R14 (既存 HTML から構成データを逆抽出して別テーマの出発点にする) の実効性に直結する

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
