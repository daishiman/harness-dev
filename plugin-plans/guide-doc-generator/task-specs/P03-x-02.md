P02 の集約判定が検出した横断矛盾の解消 leaf。P03 phase 本文が成果物として宣言する「指摘に対する設計修正の反映」に対応するが、P03-x-01 の write_scope が `evidence/P03.json` に限られ briefs/ を含まないため、宣言成果物を write_scope 内で達成できない仕様欠落があった。本 leaf はその欠落を埋める。

矛盾は独立 context の並列 agent が同じ概念に別名を与えたことに由来するため、解消は**単一 writer** が briefs/ 全体を見渡して行う。多数決ではなく、各概念の単一正本を持つ component の宣言を起点に揃える。
