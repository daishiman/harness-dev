- 対象: `plugins/guide-doc-generator/tests/validate-handout-config.py/` 配下の新規・既存テスト、`plugins/guide-doc-generator/examples/` 配下の同梱構成データ・期待値。

## 書き直す内容

1. **REQ-7 (C73・最優先)**: `block_body_max_chars_by_detail_level` を overview=60 / standard=100 / detailed=160 とした examples の本文長を新上限内に収め直す。1文60字・1本文3文・折り畳み逃避0件が error として機能することを確認する新規テスト `test_long_text_gate.py` を追加し、finding 由来の再現ケース (750字 TEXT を B10 へ入れて `--normalize` しても exit0 で通っていた旧挙動) を non-zero exit になる regression test として固定する。
2. **REQ-2(b) (C68) — 2026-08-18 追補反映**: 判定単位は資料全体の総量比 (`min_diagrams_per_main_sections` value=0.4/0.6・floor=2) ではなく main セクション単位の下限 (`min_diagrams_per_main_section=1` / level=error) である。診断件数 (`required=max(floor, ceil(main_count*value))`) を仮定していたテストの期待値を、main セクションを 1 件ずつ走査し DIAGRAM を欠く節を error 列挙する形へ書き換える。examples/ の同梱構成データは全 main セクションに DIAGRAM を最低 1 件持つよう書き直す。
3. **REQ-3(a)(b) (C69) — 新規追加**: 新設コード `E-IMAGE-ABSENT` (`min_images_per_main_section=1` / level=error) を検査するテストを追加する。旧被覆 (IMG は lecture プリセットの demo 節のみ、または「lecture 以外の 7 プリセット」への限定配線) を仮定した examples/tests の fixture は、2026-08-18 追補により lecture を含む全 8 プリセットの全 main セクションが IMG を必要とする前提へ書き直す。screenshot 役の素材が無いセクションを illustration へ fallback させたケースが exit0 で通ることも regression test として固定する。
4. **REQ-6 (C72)**: 出力ディレクトリ命名を `<YYYY-MM-DD>_<主題slug>/` へ揃え、旧 `<YYYY-MM-DD>-<種別>-<主題slug>/` を仮定するテスト・examples のパス表記を更新する。
5. 上記以外の C67/C70/C71 は本 leaf の直接の書き直し対象ではないが、examples の資料が生成された際に矛盾なく通ることを最終確認する (担い手は C11/C21/C23/C20 の各 leaf)。
