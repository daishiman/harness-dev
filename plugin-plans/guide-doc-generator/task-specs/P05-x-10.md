`P05-C06-01` が build 中に発見したタスク。発見理由は次のとおり。

> tests/handout-readability-reviewer/test_no_side_effects.py:23-29 の test_only_one_agent_definition_for_c06 が PLUGIN_ROOT.glob('**/handout-readability-reviewer.md') で plugin ルート全域を再帰探索し、C03 の受入 fixture tests/assign-handout-readability-evaluator/fixtures/accept/agents/handout-readability-reviewer.md を第2の agent 定義として誤検出するため恒久的に赤になる。守るべき不変条件は production surface の agent 定義が 1 本であることで、tests/fixtures は production surface ではない。テストを書いた leaf は既に done のため受け皿が無い

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
