`P05-C11-01` が build 中に発見したタスク。発見理由は次のとおり。

> C11 の fixture base_config() が provenance.normalized_by を持たない未正規化 config を C18 / C22 へ渡すため、両 script が仕様どおり exit 2 (構成データが正規化済みでない) を返し HTML が読まれる前に落ちる。C18 / C22 側で吸収すると未正規化 config を検証通過させる穴になるため吸収不可。fixture の owner である P04-x-06 は既に done

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
