- 非対象: `plugins/guide-doc-generator/examples/` および `tests/validate-handout-config.py/` (owner は `P05-x-03` / `P05-x-25`)。producer は 1 つまでの規則 (`validate-task-graph.py:123` 系) を守るため、本 leaf はそれらへ書かない。
