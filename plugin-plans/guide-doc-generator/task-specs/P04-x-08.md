`P04-x-07` の裁定をテストへ固定する leaf。P04 の規律に従い、**実装は一切書かない**。

## 固定すべき赤

裁定 (a)-(e) に 1:1 対応させる。既存の `tests/srg-image-bridge.py/` は P04-C21-01 が固定し P05-C21-01 が緑にしたディレクトリなので、**既存 assert を弱めずに追加する**。特に `DelegationOnlyTest` (プロンプト本文の組み立て・genome 複製・画像生成 API 呼出しが 0 件であること) は R23 で最も壊れやすい検査なので、追加テストがこれと矛盾しないことを自分で確認する。

1. **(a)**: `textPolicy` の既定が `baked-with-overlay` であること。`overlayText` が空の slide は exit2 になること。`overlay-only` を明示指定したときは焼き文字なしのプロンプトになること。
2. **(b)**: 焼き込みブロック数と 1 ブロック文字数の確定値をそのまま検査すること。**確定値を 2 箇所に書かない** — 値の正本は RESOLUTION-R23 が指す 1 箇所であり、テストはそこから読むか、テスト側 `_support` の単一定数として持ち他は参照する。句点を含む完全文が exit1 / exit2 のいずれかになることを固定する。
3. **(c)**: style family が 2 系統選べること。既定の決定論選択 (用途種別 × 図解型 → family) が表として検査されること。`plugins/guide-doc-generator/genomes/` の genome を `--genome` へ渡す経路が存在すること。**genome ファイルの内容をテスト側へ写さない** (写すと正本が二重化する。`P05-x-04` の産出物を読む)。
4. **(d)**: 平坦化の代理指標。裁定が採用した指標だけを検査し、画素判定を持ち込まない。
5. **(e)**: 同一資料内の全セクションが同一の図解型・被写体構成になっている画像計画が拒否されること。

## 禁止事項

- 実装ファイル (`plugins/guide-doc-generator/scripts/`) を変更しない。
- 既存の緑を維持するために新テストを緩めない。R23 由来の赤は `P05-C21-01` の再実装 (`--reactivate-cascade` で pending へ戻す) と `P05-C05-01` が緑にする。
- テストは Python 3.10+ 標準ライブラリのみの `unittest` で書く。
