`P05-C01-01` が build 中に発見したタスク。発見理由は次のとおり。

> tests/run-handout-build/reject_cases.py:110-114 の non-interactive-path-blocked が恒久的に検出不能。contract_lib.py:423-427 の AC-C01-19 検出条件は body 全体への部分文字列一致だが、reject 置換は fixtures/accept/.../SKILL.md:111 の 1 行しか書き換えないため、別箇所に残る『入力: 題材と素材、または検証済みの構成データ。』と見出し『## ヒアリングと非対話経路』が両条件を満たしてしまう。述語が緩すぎて reject fixture を違反状態にできない欠陥で、C01 の実装内容によらず赤のまま

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
