`P05-C20-01` が build 中に発見したタスク。発見理由は次のとおり。

> tests/extract-handout-config.py/test_marker_extraction.py:112-123 が rows[].key を要求するが schemas/handout-config.schema.json の $defs.part_data.B03 は additionalProperties:false かつ properties が num/text/time/sub のみで key を持たない。テストを満たすと C12 で E-KEY-UNKNOWN が出て、C12 を満たすとテストが赤になる相互排他。C20 worker はテスト変更禁止の規律下でテスト側を採用したが、どちらが正本かの決定が未了

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
