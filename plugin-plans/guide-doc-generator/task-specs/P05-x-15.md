`P05-C07-01` が build 中に発見したタスク。発見理由は次のとおり。

> component-inventory.json の argument_hint 列が brief の後追いをできておらず、C09 と C07 の 2 件で canon-conflict が発生した。C07 は inventory が 3 引数版のまま (実測) で成果物は brief 準拠の 6 引数版、C09 も inventory が短い形のまま。テストは brief を正本とするため build は正しく通るが、AC-Cxx-1 の『frontmatter が inventory と一致』を字義通り読むと不一致。inventory は他 leaf の criteria_ref でもあるため放置すると別 leaf が旧表記を前提に組む

## 進め方

- 受入基準は frontmatter の `acceptance_criterion` が正本。ここに再掲しない。
- `write_scope` の外へ書かない。scope 外の是正が必要と判明したら、その場で直さず discovered-task として起票する。
- 緑にするために既存 assert を弱めない。弱める必要があると判断した場合は裁定事項として起票する。
- テストは Python 3.10+ の標準ライブラリのみの `unittest` で書く。
