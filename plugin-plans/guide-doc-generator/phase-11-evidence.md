# P11 — evidence (検証)

## 目的

ここまでの判定を裏づける証跡を収集して保全し、evidence gate を成立させる。「通った」という主張ではなく、再検証可能な出力そのものを残す。

## 背景

証跡が無い合格は主張にすぎない。特に本 plugin は二値判定可能な要件が多いため、実行出力をそのまま証跡にできる。逆に注釈つきの要約だけを残すと再検証不能になる。

## 前提条件

- P10 の final-gate が PASS している

## ドメイン知識

- **証跡の粒度**: 実在するファイルパスと実行出力を残す。注釈や要約は証跡の本体ではなく付記として分ける
- **再検証可能性**: 第三者が同じコマンドを実行して同じ結果を得られること
- **生成物の証跡**: 実題材で生成した資料 1 式を、構成データとセットで保全する

## 成果物

- 全ゲートの実行出力
- 実題材の生成物 1 式 (資料 HTML / 構成データ / 素材 / README)
- 再現性の確認記録 (同一構成データからの再生成)
- 委譲先不在時の縮退動作の記録

## スコープ外

- 利用者向け文書の作成 (P12)
- 配布判断 (P13)

## 完了チェックリスト

- [ ] 全ゲートの実行出力が実在ファイルとして保全されている
- [ ] 実題材の生成物が構成データとセットで残っている
- [ ] 再現性の確認記録がある
- [ ] evidence gate が PASS である

### 受入例 (満たす例 / 満たさない例)

- 満たす例: 各ゲートの実行出力が実在ファイルとして保全され、注釈ではなく裸のパスで参照できる。実題材の生成物が構成データとセットで残っている。
- 満たさない例: 「全ゲート PASS」という宣言だけがあり、再実行できる一次証跡が残っていない。

### 事前解決済み判断

- 証跡は裸の実在パスで残す。コマンド名・exit code・注釈は所見欄へ置き、証跡パスへ混ぜない (実在しない証跡での緑化を防ぐ)。
