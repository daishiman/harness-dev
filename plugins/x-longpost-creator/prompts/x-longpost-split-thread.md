# Task仕様書：スレッド分割

## 1. メタ情報

| 項目     | 内容              |
| -------- | ----------------- |
| 名前     | Thread Splitter   |
| 専門領域 | SNS投稿最適化     |

---

## 2. 目的

投稿文（長文）を140文字程度のスレッド形式に分割し、X（Twitter）での投稿に最適化する。

## 3. 責務

| 責務               | 成果物           |
| ------------------ | ---------------- |
| スレッド分割       | 投稿文（分割）   |
| 番号付与           | 【n/N】形式      |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 投稿文（長文）を読み込む                 |
| 2        | 意味的な区切りポイントを特定             |
| 3        | 140文字を基準に分割                      |
| 4        | 各ツイートが独立して読めるか確認         |
| 5        | 重要メッセージは最初と最後に配置         |
| 6        | 番号を付与                               |
| 7        | 投稿文（分割）を出力                     |

### 4.2 分割ルール

| ルール             | 説明                               |
| ------------------ | ---------------------------------- |
| 文字数             | 140文字以内                        |
| 区切り位置         | 文末、段落の境界                   |
| 独立性             | 各ツイートが単独で意味を持つ       |
| 連続性             | 前後の流れが自然                   |

### 4.3 番号形式

- **形式**: 【n/N】
- **位置**: 各ツイートの先頭
- **例**: 【1/15】、【2/15】...

### 4.4 配置戦略

| 位置               | 内容                               |
| ------------------ | ---------------------------------- |
| 最初のツイート     | ホリゾンタルフック（普遍的欲求で広く入る） |
| 中間のツイート     | 本文の展開                         |
| 最後のツイート     | 締めくくり・行動喚起               |

最初のツイートはホリゾンタルフックにする。読者の普遍的欲求（時間・お金・楽・不安解消・評価・変化）で広く入り、テーマの直提示（「今回のテーマは〜です」等の定型文）は禁止（`../references/horizontal-vertical-guide.md` §8）。

### 4.5 チェックリスト

| 項目               | 基準                     |
| ------------------ | ------------------------ |
| 全ツイート140文字以内 | 超過なし               |
| 番号が正しいか     | 連番、総数が正確         |
| 独立して読めるか   | 各ツイート単独で理解可   |
| 流れが自然か       | 順番に読んで違和感なし   |

---

## 5. 出力テンプレート

```markdown
# 投稿文（分割）

【1/n】
================================

[タイトル/キャッチコピー]

================================

【2/n】
================================

[導入・問いかけ]

================================

【3/n】
================================

[具体的な悩み]

================================

...

【n/n】
================================

[締めくくり・感謝]

================================
```

## 6. 分割例

```
【1/15】
================================

AIの出力が思い通りにならなくて、
同じ指示を何度も
書き直していませんか。

実は、直すべきは
指示の書き方じゃないんです。

================================

【2/15】
================================

みなさん、こんな経験ありませんか？

「プロンプトの出力精度が安定しない」
「どうやって直せばいいか分からない」

================================

【3/15】
================================

プロンプトの調整って、
簡単そうに見えて難しいんですよね。

作るのは1時間でも、
調整に3週間かかったことがあります。

================================
```
