# Task仕様書：構成要素抽出

## 1. メタ情報

| 項目     | 内容            |
| -------- | --------------- |
| 名前     | Input Parser    |
| 専門領域 | 要素抽出・構造化 |
| Phase    | 1（長文投稿ワークフロー） |
| 入力元   | ①ユーザーが手動で用意したメモ（従来フロー）、または②`x-longpost-structure-transcript`が生成した構造化メモ（文字起こしフロー） |

---

## 2. 目的

キャッチコピーとメモから、X長文投稿に必要な構成要素を抽出・構造化する。

**文字起こしワークフロー時**: `x-longpost-structure-transcript`が出力した構造化メモ（見出し付き日本語文章）を「メモ」として受け取り、同様に処理する。構造化済みであるため、そのまま構成要素抽出に使用できる。

## 3. 責務

| 責務               | 成果物           |
| ------------------ | ---------------- |
| 構成要素の抽出     | 構成要素リスト   |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | キャッチコピーから核心メッセージを特定   |
| 1.5      | **投稿の「軸」を1つに決定する（AI編集原則①）** |
| 2        | メモから以下のカテゴリに分類             |
| 3        | 各カテゴリで6項目以上を抽出              |
| 4        | 簡潔な表現（1-2文）に変換                |
| 5        | **抽出した要素が「軸」と矛盾しないか検証** |
| 5.5      | **矛盾発見時の対応: ①軸と無関係な要素→除外、②軸と部分的に矛盾→軸に沿うよう修正、③軸が2つ以上に分裂→ユーザーに確認** |
| 6        | 構成要素リストを出力                     |

**ステップ1.5「軸」決定の重要性**:
AIの文章は主張が曖昧になりがち。メモに複数のテーマが含まれていても、
投稿全体を貫く「軸」を1つだけ決め、全段落がその軸を補強する構成にする。
軸が2つ以上になる場合は、どちらを主張にするかユーザーに確認する。

### 4.2 抽出カテゴリ

1. **キャッチコピー**: 核心メッセージ3パターン（うち1つ以上は普遍的欲求ベースのホリゾンタル入口）
2. **目的**: 投稿で達成したい具体的な目的
3. **最も言いたいこと**: 核心メッセージ3つ
4. **理想の状態**: 具体的な理想6項目
5. **現状**: 現在の問題6項目
6. **ギャップの根本原因**: 根本原因6項目
7. **このままいくとどうなる**: 将来予測6項目
8. **最悪の未来**: 最悪シナリオ6項目
9. **解決に必要なこと**: 解決策6項目
10. **こんな人が増えると**: ポジティブな未来6項目
11. **読者の普遍的欲求**: この話は読者のどんな変化に効くか（6カテゴリ: 時間・お金・楽・不安解消・評価・変化。正本§3参照）

> 「読者の普遍的欲求」の6カテゴリ・欲求翻訳の詳細は正本 [../references/horizontal-vertical-guide.md](../references/horizontal-vertical-guide.md) を参照。

### 4.3 チェックリスト

| 項目               | 基準                     |
| ------------------ | ------------------------ |
| 11カテゴリあるか   | 全カテゴリを網羅         |
| 各6項目以上か      | 60項目以上               |
| 簡潔か             | 各項目1-2文              |
| 中学生理解レベルか | 専門用語を平易に         |
| **軸が1つに決定されたか** | **2つ以上ある場合はユーザー確認済み（AI編集原則①）** |
| 読者の普遍的欲求が特定されているか | 6カテゴリのいずれかに接続し、専門語のままでない（正本§3） |
