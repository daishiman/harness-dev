# スタイルゲノム詳細仕様

## 概要

スタイルゲノムは、個人の文体特徴を8つのレベルで体系化したものです。
X長文投稿の作成時に、このスタイルゲノムを適用することで一貫性のある個人文体を実現します。

**重要**: ユーザーのメモ内容を最優先とし、スタイルゲノムはその表現方法として適用する。
固定フォーマットで文章を作るのではなく、ユーザーの意図を維持しながら読みやすく整える。

---

## L1: 表層的言語特徴

### 字種選択

| 項目 | 設定値 | 説明 |
|------|--------|------|
| 漢字使用率 | 約28% | 読みやすさ優先 |
| ひらがな率 | 約58% | 柔らかい印象 |
| カタカナ率 | 約14% | 技術用語に集中 |

**ひらがな化推奨**:
- 「事」→「こと」
- 「出来る」→「できる」
- 「様々」→「さまざま」
- 「是非」→「ぜひ」

**漢字維持**: 専門用語、固有名詞、AI、JSON、API等

### 文字数・改行

| 項目 | 設定値 |
|------|--------|
| 平均文長 | 25-35文字/文 |
| 最短文 | 5-8文字（強調用） |
| 最長文 | 60-80文字（説明文） |
| 改行頻度（絶対） | **句点（。）で終わる1文につき必ず1回以上改行する。1行に2文以上（。が2つ以上）を混在させない** |
| 改行位置 | 文脈（文節・意味の区切り・句読点「、。」）で改行する。単語・文節の途中では絶対に改行しない |
| 1行の長さ | 目安30-40字程度。1文がこれを超える場合は読点「、」の切れ目でさらに行を分ける（目安幅に最も近い自然な区切りで切り、文字数ぴったりでは切らない・単語や文節の途中では切らない） |

**具体例**:
```
短文: 「これが大事です。」（8文字）
中文: 「プロンプトの調整って、簡単そうに見えて難しいんですよね。」（32文字）
長文: 「プロンプトを詳細に記述していても、コンテキストオーバーで情報が薄れてしまう。」（43文字）
```

### 句読点・記号

| 項目 | ルール |
|------|--------|
| 読点 | 約2-3回/100文字（少なめ） |
| 疑問符 | 問いかけで頻繁に使用 |
| 感嘆符 | 控えめ |
| 波ダッシュ | 語尾の伸ばし（「〜」） |
| 括弧 | 補足説明に使用 |

## L2: 語彙・表現

### 代名詞

| 項目 | 設定値 |
|------|--------|
| 一人称 | 「僕」（「私」は使わない） |
| 二人称 | 「みなさん」「方」（「あなた」は避ける） |

### 副詞

| カテゴリ | 表現 |
|----------|------|
| 強調 | めっちゃ、結構、かなり |
| 変化 | どんどん、少しずつ |
| 程度 | ほぼ、全然 |

### 動詞

| 項目 | 設定値 |
|------|--------|
| 能動態 | 95%（受動態はほぼ使わない） |
| 頻出 | やる、作る、使う、できる、なる |

### 接続詞

| 種類 | 表現 |
|------|------|
| 逆接 | でも、ただ、けど |
| 順接 | だから、なので、そこで |
| 添加 | そして、あと、それに |
| 転換 | じゃあ、ところで |

### 文末表現

| パターン | 用途 |
|----------|------|
| 〜です | 断定 |
| 〜ます | 行動 |
| 〜んですよね | 共感・説明 |
| 〜と思います | 推測・意見 |
| 〜かなと | 控えめな推測 |

## L3: 統語構造

### 文型比率

| 種類 | 比率 | 説明 |
|------|------|------|
| 単文 | 60% | 主語+述語のシンプルな文 |
| 重文 | 25% | 対等な節の接続 |
| 複文 | 15% | 従属節を含む文 |

### 修飾関係

- シンプル寄り
- 連体修飾は短く簡潔
- 連用修飾は副詞中心

### 主語の明示/省略

| 状況 | 対応 |
|------|------|
| 「僕」の行動 | 明示（約40%） |
| 文脈で明らか | 省略（テンポ優先） |

## L4: 談話構造

### 基本展開パターン

```
1. 問いかけ・共感
   └ 「こんな経験ないですか？」

2. 共感表明
   └ 「僕も今同じ壁にぶつかっています」

3. 問題分析
   └ 「なんでこんなことが起きるのか」

4. 原因説明
   └ 「一つのプロンプトで〜」

5. 解決策提示
   └ 「答えはシンプルで」

6. 具体例・実践
   └ 「具体的には〜」

7. 今後の展望
   └ 「これからは〜」

8. 読者への呼びかけ
   └ 「一緒に〜」
```

**ホリゾンタル入口**: 1問いかけ・共感は読者の普遍的欲求・日常の悩みの言葉で書き、専門語を避ける（horizontal-vertical-guide.md 参照）。専門語・ツール名は共感形成後（3問題分析以降）に初出させる。

### トピック転換

| 方法 | 例 |
|------|-----|
| 空白行 | 話題転換の明示 |
| 転換マーカー | 「じゃあ、どうすればいいか。」 |
| 問いかけ | 「なんでこんなことが起きるのか。」 |

### 強調手法

| 手法 | 例 |
|------|-----|
| 繰り返し | 「〜です。〜です。〜です。」 |
| 対比 | 「以前は〜、今は〜」 |
| 短文での強調 | 「これが大事。」 |

## L5: 修辞・リズム

### 文長パターン

```
短 → 中 → 長 → 短

例：
「でも、出力精度がばらついてしまう。」（短）
「ワークフローの接続が成功したり、失敗したりと不安定です。」（中）
「グループごとの説明コメントも、出たり出なかったり。」（短）
```

### 反復構造

- 「〜たり、〜たり」パターン
- 三題話法（3つの要素を並列）
- 同じ構造の文の連続

### 文体の格式

| 項目 | 設定 |
|------|------|
| フォーマリティ | カジュアル寄りのセミフォーマル |
| トーン | 友人に語りかけるような親しみやすさ |
| 特徴 | 技術的内容でも砕けた表現 |

## L6: 認知・思考パターン

### 情報処理スタイル

```
ボトムアップ型: 具体 → 抽象 → 具体

1. 具体的な事例・体験から開始
   「やってみて→」

2. パターンや本質を抽出
   「気づいて→」

3. 再び具体的な適用例へ
   「原則化する」
```

### 因果関係の明示

- 「だから」「なので」を積極使用
- 単純因果を基本
- 原因→結果を明確に提示

### 数量表現

- 具体的数値を積極使用
- 「50名以上」「1時間」「13ステップ」
- 曖昧な「多くの」「少し」は避ける

### 時間軸

| 時制 | 比率 | 用途 |
|------|------|------|
| 現在 | 50% | 現在の取り組み |
| 過去 | 30% | 過去の失敗や学び |
| 未来 | 20% | 今後の展望 |

## L7: 価値観・世界観

### 暗黙の前提

| 前提 | 表現 |
|------|------|
| 完璧より実践 | 「やってみないと分からない」 |
| 失敗は学び | 「作って終わりじゃない」 |
| AIと人間の協働 | 「使いながら改善する」 |

### 優先価値

```
1. 実用性 > 理論的完璧性
2. 動くもの > 完璧なもの
3. 実践知 > 理論知
4. プロセスの透明性
5. 継続的改善
```

### 倫理的スタンス

- 透明性重視
- 失敗も含めて正直に共有
- 自身の失敗や課題を隠さず開示

### リスク許容度

- 積極的
- 失敗を恐れず挑戦
- 「まずやってみる」

## L8: 対人関係・コミュニケーション

### 社会的距離

| 項目 | 設定 |
|------|------|
| 距離感 | 適度に親密、友人に語るよう |
| 敬語 | 丁寧語基本、尊敬語・謙譲語は最小限 |

### 自己開示

| 項目 | 設定 |
|------|------|
| レベル | 高い |
| 内容 | 失敗体験、試行錯誤、現在の悩み |

### 共感表現

| パターン | 例 |
|----------|-----|
| 問いかけ | 「こんな経験ないですか？」 |
| 共感表明 | 「僕も今同じ壁にぶつかっています」 |
| 呼びかけ | 「一緒に作りましょ〜！」 |

### 読者との関係性構築

```
1. 問いかけで共通体験を作る
   └ 「こんな経験ないですか？」

2. 失敗開示で信頼を構築
   └ 「僕も今同じ壁にぶつかっています」

3. 解決策の共有
   └ 「一緒に解決しましょう」
```

### 対話性

| 項目 | 設定 |
|------|------|
| 傾向 | 高度に対話的 |
| 読者の存在 | 常に強く意識 |
| 手法 | 問いかけと応答の構造 |

|--------|----------|
| L1 | **句点（。）を含む行が2文以上になっていないか（1文=1行が絶対）？** 改行が文脈（文節・句読点）で行われているか？単語・文節の途中で切れていないか？1行が目安30-40字程度の自然な区切りか？空白行は適切か？ |

| L7 | 実用性重視の姿勢か？ |
| L8 | 問いかけ・共感があるか？**対話的文末（〜んですよね、〜かなと、〜と思います）が混在しているか？「です」「ます」が3文以上連続していないか？** |
