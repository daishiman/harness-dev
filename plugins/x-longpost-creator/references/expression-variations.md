# 表現バリエーションライブラリ

## 概要

毎回同じ文章にならないよう、冒頭フック・接続詞・文末・締めの表現を
バリエーションライブラリから選択して適用する。

**重要**:
- 毎回異なる表現バリエーションを選択し、単調な出力を避ける
- 構造・技法は維持しつつ、言い回しを変える
- 過去に使用していないバリエーションを優先
- フック用の普遍的欲求の言葉は horizontal-vertical-guide.md §3.2 の6カテゴリを参照（フックはホリゾンタル入口とし、専門語でなく欲求語で埋める）

## 接続詞バリエーション

### 逆接

| 表現 | ニュアンス |
|------|------------|
| でも | カジュアル、口語的 |
| ただ | 補足・例外を示す |
| けど | 口語的、柔らかい |
| しかし | やや硬め、強調 |
| とはいえ | 譲歩のニュアンス |

### 順接（原因・理由）

| 表現 | ニュアンス |
|------|------------|
| だから | 直接的な因果 |
| なので | 柔らかい因果 |
| だからこそ | 強調された因果 |
| そのため | やや硬め、論理的 |
| それで | 自然な流れ |

### 順接（追加）

| 表現 | ニュアンス |
|------|------------|
| そして | 標準的な追加 |
| さらに | 程度の追加 |
| 加えて | フォーマル寄り |
| しかも | 驚きを伴う追加 |
| それに | カジュアルな追加 |

### 転換

| 表現 | ニュアンス |
|------|------------|
| じゃあ | カジュアル、話し言葉 |
| では | ややフォーマル |
| そこで | 論理的な転換 |
| ここで | 注目を促す転換 |
| というわけで | まとめ的な転換 |

## 文末バリエーション

### 断定

| 表現 | ニュアンス |
|------|------------|
| 〜です | 標準的な断定 |
| 〜なんです | 強調、説明的 |
| 〜なんですよね | 共感を求める断定 |
| 〜だと思ってます | 個人的見解としての断定 |
| 〜と考えています | やや硬め、論理的 |

### 推測・柔らか

| 表現 | ニュアンス |
|------|------------|
| 〜と思います | 標準的な推測 |
| 〜かなと | 控えめな推測 |
| 〜かもしれません | 可能性を示す |
| 〜じゃないかな | カジュアルな推測 |
| 〜気がします | 感覚的な推測 |

### 提案

| 表現 | ニュアンス |
|------|------------|
| 〜するといいです | 柔らかい提案 |
| 〜がおすすめです | カジュアルな推奨 |
| 〜してみてください | 行動を促す |
| 〜するのが大事 | 重要性を強調 |
| 〜が効果的です | 効果を示す |

## 締めの言い回しバリエーション

### 展望型

読者の未来に対する希望・期待を示す締め。

| 表現 | 用法 |
|------|------|
| これができれば、[成果]に大きく近づきます。 | 成果への道筋を示す |
| [成果]への道が開けます。 | 可能性を示唆 |
| [成果]が見えてくるはずです。 | 確信を込めた予測 |
| きっと[成果]に繋がります。 | 励ましを込めた予測 |

### 教訓型

普遍的な学びや気づきを示す締め。

| 表現 | 用法 |
|------|------|
| やはり何事も[行動]するとちゃんとリターンがあるものだと思います。 | 普遍的な教訓 |
| 結局、[行動]が一番大事なんですよね。 | 本質を強調 |
| [行動]を続けることで、見える景色が変わります。 | 継続の価値 |

### アドバイス型

実践的な行動指針を示す締め。

| 表現 | 用法 |
|------|------|
| [解決策]で守る。[詳細]ほど[効果]。 | 具体的な方法提示 |
| 大事なのは[解決策]。これで[効果]が変わります。 | 重要性の強調 |
| [解決策]に徹することが大事。 | シンプルな行動指針 |

### 強調型

結論を力強く示す締め。

| 表現 | 用法 |
|------|------|
| この組み合わせが最適解かなと。 | 控えめな確信 |
| これが答えだと思ってます。 | 強い確信 |
| ここに尽きると思います。 | 本質への帰結 |

## 問いかけバリエーション

### 共感喚起

読者との共通体験を確認する問いかけ。

| 表現 | 効果 |
|------|------|
| こんな経験ないですか? | 共通体験の確認 |
| これ、心当たりありませんか? | 自己反省を促す |
| 同じこと感じたことないですか? | 共感の確認 |
| 僕だけじゃないと思うんですが。 | 仲間意識の形成 |

### 自問自答

論理展開を促す問いかけ。

| 表現 | 効果 |
|------|------|
| なんでこんなことが起きるのか。 | 原因への誘導 |
| じゃあ、どうすればいいか。 | 解決策への誘導 |
| 何が違うのか。 | 対比への誘導 |
| ここからが核心です。 | 重要ポイントへの注目 |

## 強調副詞バリエーション

### 強い強調

| 表現 | ニュアンス |
|------|------------|
| めっちゃ | カジュアル、強い |
| かなり | やや硬め、強い |
| 相当 | フォーマル寄り |
| 本当に | 真実味を強調 |
| マジで | 口語的、驚き |

### 中程度の強調

| 表現 | ニュアンス |
|------|------------|
| 結構 | カジュアル |
| わりと | 控えめ |
| 意外と | 予想外を示す |
| 思った以上に | 比較を含む |

### 変化を示す

| 表現 | ニュアンス |
|------|------------|
| どんどん | 加速感 |
| 少しずつ | 漸進的 |
| 徐々に | やや硬め |
| だんだん | 自然な変化 |

## 適用ルール

### 選択基準

1. **前回と異なる表現を選ぶ**: 同じ投稿内で同じ表現の繰り返しを避ける
2. **文脈に合った表現を選ぶ**: カジュアル/フォーマルのトーンを統一
3. **リズムを意識する**: 短い表現と長い表現をバランスよく配置

### バリエーション適用例

**元の文章**:
```
プロンプトが思い通りに動かない。
でも、原因は意外とシンプルだった。
なので、これを解決すれば成果が出る。
```

**バリエーション1**:
```
プロンプトが思い通りに動かない。
ただ、原因は結構シンプルだったんです。
だからこそ、これを解決すれば成果に繋がります。
```

**バリエーション2**:
```
プロンプトが思い通りに動かない。
けど、原因はわりとシンプルなんですよね。
そのため、これを解決すれば成果が見えてきます。
```

### チェックリスト

| 項目 | 確認内容 |
|------|----------|
| 接続詞 | 同じ接続詞を連続で使っていないか |
| 文末 | 同じ文末表現が3回以上続いていないか |
| 強調副詞 | 適切な強度の副詞を選んでいるか |
| 締め | 前回と異なる締め方を選んでいるか |
| 冒頭フック | フォーマットに合った冒頭フックを選んでいるか |
| フックの専門語 | フックに専門語が残っていないか（欲求翻訳済みか） |
