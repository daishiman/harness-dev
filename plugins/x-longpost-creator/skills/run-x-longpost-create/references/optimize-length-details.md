## 1. AI文章編集の4原則チェック（最適化時に必須適用）

文章最適化の最終段階で、以下の4原則に基づくチェックを行う。
詳細: [references/writing-guidelines.md §8](writing-guidelines.md)

**このエージェントでの4原則の役割**: 原則③④を主担当、原則①②は最終確認。
- 原則③: 抽象的なAI表現が残っていないか最終チェック・具体化
- 原則④: 締めのフレーズが印象的か最終チェック・書き直し
- 原則①②: apply-style-genomeが主担当済み。最適化で軸やフックが崩れていないか確認

| 原則 | 責務 | チェック内容 | 不合格時のアクション |
|------|------|------------|-------------------|
| ①主張を明確にする | 最終確認 | 投稿全体の「軸」が1つに絞られているか | 矛盾する主張を削除・統合し、1つの軸に集約 |
| ②冒頭に命をかける | 最終確認 | 最初の1-2文に意外性・フックがあるか。冒頭が普遍的欲求ベースか。専門語・属性の重ね掛けで入口が狭まっていないか（ホリゾンタル入口） | 逆説・具体描写・問いかけで書き直す |
| ③とにかく具体的に書く | **主担当** | 抽象的な表現が残っていないか | 「何を」「どうやって」「なぜ」に答える具体表現に置換 |
| ④締めはフレーズを残す | **主担当** | 最後の1-2文が印象的なフレーズになっているか | 思い出しやすいフレーズに書き直す |

**具体性と文字数のトレードオフ**:
具体的に書くほど文字数は増える。1800〜2200文字（中心値2000文字）の制約内で具体性を確保するには：
- 最も重要な1-2箇所を行動レベルまで具体化し、他は適度な具体性に留める
- 「具体例を1つだけ深く書く」方が「浅い例を3つ並べる」より効果的
- 冗長な前置きや重複を削って、具体的記述のスペースを確保する

**典型的なAI文章のNG → OK変換例**は [references/writing-guidelines.md §8](writing-guidelines.md) を参照。

## 2. AI臭6分類の最終チェック（もとやま分類）

最適化の最終段階で、AI臭が残っていないかチェックする。
詳細: [references/writing-guidelines.md §9](writing-guidelines.md)

**このエージェントでの役割**: 分類⑤を主担当（最終チェック）、分類①②③④⑥は確認のみ。
- 分類⑤: 最適化段階で残りやすい「抽象語」を最終排除
- 分類①②③④⑥: apply-style-genomeが主担当済み。最適化で再発していないか確認

| 分類 | 責務 | 最終チェック内容 |
|------|------|---------------|
| ④事なかれ | 確認 | 圧縮後に保険表現・ケースバイケース逃げが再発していないか |
| ⑤抽象語 | **主担当** | 万能語（重要/効果的/最適/本質）だけで押し切っている箇所がないか |
| ⑥定番比喩 | 確認 | 圧縮後に定番比喩が再発していないか |
| ①記号 | 確認 | emダッシュ、／、（）逃げ等の記号残りが再発していないか |
| ②リズム | 確認 | 語尾連続、接続詞過多が最適化で再発していないか |
| ③説明書 | 確認 | 前置き・構造宣言が最適化で再発していないか |

## 3. 文脈改行のルール（パターンA）

| 改行する箇所 | 理由 |
|--------------|------|
| 話題が変わる箇所 | 読者の頭を切り替えるため |
| 「。」で1つの意味がまとまる箇所 | 意味の区切りを明確に |
| 問いかけの後 | 読者に考える間を与える |
| 結論・主張の前後 | 強調効果 |
| **かぎ括弧が複数ある場合** | **括弧ごとに改行して視認性向上** |

| 改行しない箇所 | 理由 |
|----------------|------|
| 1つの文の途中 | 文章が分断されて読みにくい |
| 関連する2-3文の間 | まとめて読んだ方が理解しやすい |
| 補足説明の途中 | 情報が分断される |

## 4. かぎ括弧複数の改行ルール（パターンA/B共通）

**1行に複数のかぎ括弧がある場合は、括弧ごとに改行する。**

```
【Before - 読みにくい】
「プロンプトは使えない」「AIはダメだ」とおっしゃる方もいます。

【After - 読みやすい】
「プロンプトは使えない」
「AIはダメだ」
とおっしゃる方もいます。
```
