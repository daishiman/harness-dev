# サムネイル版面規範（X / note）

> **責務**: サムネイル2種の**版面と寸法**、および図解との意味的な差分だけを説明する。kind・生成/納品寸法・比率・palette の機械判定は [visual-spec.json](visual-spec.json) が、画風・配色・禁止事項は [thumbnail-style-canon.md](thumbnail-style-canon.md) が正本である。

## 1. 寸法

| 種別 | 納品比率 | 納品寸法 | 生成寸法 | 用途 |
|------|----------|----------|----------|------|
| 図解 | 16:9 | 2560x1440 | 2560x1440 | 長文投稿の冒頭に置く本文の構造図 |
| X サムネイル | 5:2 | 1500x600 | 2560x1024 | X のリンクカード・投稿添付 |
| note サムネイル | 約 1.91:1 | 1280x670 | 1280x670 | note 記事のヘッダ |

note は生成時点から実寸 1280x670 とし、そのPNGをそのまま納品する。X は 5:2 の高解像度 2560x1024 で生成する。標準の `validate-visual-assets.js` はサムネイル2種だけを strict 検証する。

## 2. 図解との役割の違い

| | 図解 | サムネイル |
|---|------|-----------|
| 目的 | 本文の論理構造を理解させる | 読む前の人の足を止める |
| 情報量 | 3ゾーン・アイコン10個前後 | 1メッセージ・アイコン1〜3個 |
| 文字 | 大見出し + 小見出し + 結論文 | **主文1本のみ**（+補助句1本まで） |
| 読了時間 | 5〜10秒 | 1秒 |

**サムネイルに図解を縮小して流用しない。** 情報量が過多になり1秒で読めなくなる。

## 3. 版面

### X サムネイル（5:2・横長）

```
+------------------------------------------------------------+
|                                              |             |
|   主文（黒・極太・16〜24字・2行まで）          |  アイコン    |
|   補助句（細字・16字以内・省略可）             |  1〜3個     |
|                                              |             |
+------------------------------------------------------------+
     左 65%（文字ゾーン）                        右 35%
```

- 主文は**長文投稿のキャッチコピー**を用いる。無ければ確定タイトルを24字以内に圧縮する
- 右のアイコンは主文の核となる概念1つを表す。3個を超えない
- 横長なので、縦方向に要素を積まない（2段まで）

### note サムネイル（1280x670・横長やや正方寄り）

```
+--------------------------------------------------+
|                                                  |
|        主文（黒・極太・16〜24字・2行まで）         |
|                                                  |
|          アイコン  →  アイコン  →  アイコン        |
|                                                  |
|        補助句（細字・20字以内・省略可）            |
|                                                  |
+--------------------------------------------------+
```

- 中央揃えの縦積み。X 版より縦に余裕があるため、アイコンを水平に3個まで並べて小さな流れを見せてよい
- ただし矢印つきの連鎖は**1本まで**。図解のような多層構造にしない

## 4. 禁止事項の所在

サムネイルは図解の画風規範（`diagram-style-canon.md`）を**継承しない**。目的が「理解させる」から「足を止める」へ変わると、最適な配色も要素密度も変わるためである。禁止事項の正本は [thumbnail-style-canon.md](thumbnail-style-canon.md) §1（TS-01〜TS-12）と §3（情報商材的意匠）にあり、本ファイルは再掲しない。

版面に直接効く3件だけ、参照の便のためここに ID を置く。実体は上記 canon にある。

| ID | ルール | 正本 |
|----|--------|------|
| TH-01 | 枠線で画面全体を囲まない（プラットフォーム側の枠と二重になる） | TS-08 |
| TH-02 | 四辺に 5% 以上の余白を確保する（トリミング時に文字が欠けるため） | TS-08 |
| TH-03 | 主文にタイトルの全文を流し込まない。24字を超えるなら圧縮する | TS-06 |

**旧 TH-04（図解と同じアイコン絵柄を使う）は廃止した。** 図解のアイコン語彙は人物の黒塗りシルエットを含むが、サムネイルは TS-03 で人物の描画を禁じているため、同じ絵柄を使えない。3枚の統一感は絵柄の共有ではなく、線の太さ・塗りの密度・簡略度をそろえること（平面ベクターの粒度）で作る。人物を含む概念の言い換え表は `prompts/x-longpost-design-thumbnail-prompt.md` §6 にある。
