# アイコン語彙表（粒度の見本）

> **この表は制限リストではない。** ここに無い概念のアイコンを作ってよい。表の役目は「どの程度まで簡略化するか」という粒度を一枚の中でそろえるための基準を示すことにある。表にある語を使うときは、この粒度から外れないようにする。

## 1. 人物（黒塗りシルエット）

顔は描き込まない。感情と役割は姿勢・持ち物・付随記号（吹き出し・汗・？マーク）で表す。

| 概念 | 描き方 |
|------|--------|
| 一人称の主体 | 椅子に座って机に向かう人、または立って正面を向く人。**ラベル文字は付けない**（VS-07） |
| 専門家 | 角帽またはスーツにネクタイ。虫眼鏡やチェック印を伴う |
| 悩む・詰まる | 頭上に「？」の吹き出し、または頭を抱える姿勢 |
| 疲弊 | 机に積まれた書類と汗の記号 |
| 協働・合意 | 2人が向き合って握手する |
| 教える・発表 | ボードの横に立って手で指す |
| 集団・多くの人 | 同じシルエットを3〜5体並べる |
| 走る・進む | 前傾で走る姿勢。上向き矢印を伴う |

## 2. 道具・システム

| 概念 | 描き方 |
|------|--------|
| AI | 角の丸い四角の顔にアンテナを付けたロボット頭部 |
| ターミナル / コード | 黒地の四角に `>_` または `</>` |
| PC / 画面 | 枠だけのモニタ。中身は最小限 |
| スマホ | 縦長角丸長方形 |
| 書類 / 成果物 | 右上を折った紙。文字は線で表す |
| チェック済み書類 | 紙にチェック印 |
| データベース | 円柱を3段重ね |
| API / 接続 | 歯車と両端に接続点のある線 |
| ファイル / フォルダ | 塗りつぶしのタブ付きフォルダ |
| 設定 / 仕組み | 歯車。2枚重ねると「機構」 |
| 工具 | レンチとドライバーの交差 |
| マイク / 音声 | 丸型マイクに音波の弧 |

## 3. 状態・評価

| 概念 | 描き方 |
|------|--------|
| 正しい / 完了 | 太いチェック印 |
| 誤り / 失敗 | **赤の ✕**（赤を使ってよい唯一の用途。VS-04） |
| 停止 | 横線1本入りの円 |
| 注意 | 三角に感嘆符 |
| 疑問 / 不明 | 「？」単体 |
| 良い | 上向き矢印つき棒グラフ |
| 悪い | 下向きの親指、または下降する折れ線 |

## 4. 時間・量

| 概念 | 描き方 |
|------|--------|
| 時間 | アナログ時計。針で長短を表す |
| 期限 | カレンダーの1日にマーク |
| 反復 | 円環の矢印 |
| 増加 | 階段状の棒に上向き矢印 |
| 数値 | 円の中に数字（例: 30 / 80） |

## 5. 思考・概念

| 概念 | 描き方 |
|------|--------|
| 思考 | 雲形の吹き出し。中に歯車や「？」 |
| ひらめき | 電球に短い放射線 |
| 目的 / 的 | 同心円の的。中心に点 |
| 目標到達 | 山頂または階段の頂点に旗 |
| 知識の蓄積 | 本を重ねる、または脳の輪郭 |
| 構造化 | 中心から枝分かれするマインドマップ |
| 工程の連なり | 角丸長方形を矢印でつないだ列 |
| 分岐 | 1本から2本に割れる矢印 |
| 選択肢 | 並んだ四角のうち1つにチェック |

## 6. 矢印（図解の骨格）

矢印は装飾ではなく論理そのものなので、太さで階層を作る。

| 用途 | 描き方 |
|------|--------|
| ゾーン間の遷移 | **最も太い黒矢印**。水平に長く引く |
| ゾーン内の順接 | 中太の短い矢印 |
| 循環 | 円弧の矢印を時計回りに閉じる |
| 双方向・往復 | 両端矢印。または上下2本の弧 |
| 帰結・落ちる先 | 下向きの短い矢印 |

## 7. 固有名詞のロゴ

X / YouTube / GitHub / Apple / Claude / OpenAI などのロゴは、本文がそのサービスを主題にしている場合のみ使う。装飾目的で置かない。ロゴは黒一色に落として粒度をそろえる。
