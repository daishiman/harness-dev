# 配色戦略・色彩設計ガイド

> **規則の正本**: [spec-registry.md](spec-registry.md) §2 と `skills/run-slide-report-generate/references/visual-generation-rules.md` §1。このファイルは「どの色を選ぶか」を判断する薄いガイドであり、色値・色数・閾値を複製しない。

## 1. 判断原則

配色は色相の選択ではなく、情報の役割を次の 3 つに分ける作業とする。

| 役割 | 表現 | 根拠 |
|---|---|---|
| 地 | `paper` 系の面 | SR-2-01 |
| 文字・罫 | `ink` 系 | SR-2-01 / SR-2-02 |
| 面の最重要 1 ブロック | 地と文字を入れ替えた反転面 | SR-2-04 / SR-2-05 |

- 一枚の中で「課題=赤、解決=緑」のように意味を色相へ割り当てない。位置、順序、ラベル、罫、形で示す（SR-2-07）。
- 強調を増やすときは色を足さず、情報の優先度を見直す。反転面が複数必要なら、面の分割候補である。
- クライアント指定のトーンに合わせる場合は、色セットを追加せず style genome の palette 自体を差し替える（SR-2-04-alt）。

## 2. スライド種別の適用

| 種別 | 適用 |
|---|---|
| タイトル / 結論 | 主メッセージを唯一の反転面にし、装飾用グラデーションは作らない |
| 数値 / 効果 | 最重要の数値ブロックだけを反転。増減は符号・矢印の向き・ラベルを併記 |
| Before / After | 左右位置と見出しで区別し、推奨側だけを反転（SR-4-04） |
| フロー | 全工程は同じ地と文字。現在地は反転面または線幅とラベルで示す |
| カード / グリッド | カードごとに色を変えない。同型は同じ意匠にし、焦点 1 件だけを反転 |
| 図解 | 内部階層に限り、VGCONST_002 の単一色相の濃度段を使う。色だけで分類しない |

## 3. 暗い面と画像の例外

コードブロック、D3 canvas、写真の上のオーバーレイなど、内容自体が暗い場合は、その局所面の地と文字を入れ替える。これはデッキ全体に第 2 テーマを追加することではない。

- 暗い面で彩度を上げない。必要なコントラストは地/文字の反転で作る。
- 写真上の文字は色だけで読ませず、安定したソリッドのオーバーレイ上に置く。
- 新規生成でグラデーションを意匠手段として追加しない。既存資料の修正で残存する場合も、情報を担わせずソリッド面へ漸進置換する。

## 4. 実装と検査

- 色値は CSS 変数と style genome の palette で管理し、HTML / SVG に直書きしない（SR-2-02 / SR-2-08）。
- アクセント変数の名前は経路ごとの生成器が正本。このガイドに変数一覧を作らない（SR-2-03）。
- 階層は影やグロウではなく罫と余白で作る（SR-2-09）。
- コントラストは SR-9-01、グレースケールと印刷は `print-layout.md` のゲートで確認する。

## 5. チェックリスト

- [ ] 地・文字・反転面の役割が明確か
- [ ] 面の強調が 1 箇所に絞られているか
- [ ] 意味が色相だけに依存していないか
- [ ] 図解外に色相の追加やグラデーションがないか
- [ ] CSS 変数・palette・印刷時の表現が同じ役割契約を保っているか
