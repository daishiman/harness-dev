# 資料作成の大原則（guide 配布境界）

このディレクトリには、guide-doc-generator が単独配布でも使える資料作成規範を置く。
役割は次の 2 つに分かれる。

| 資産 | owner | 更新方法 |
|---|---|---|
| `principles.json` / `tool-adapters.json` / `scripts/select-deck-principles.py` | slide-report-generator | 上流の `vendor-manifest.json` が同期対象と digest を固定する generated byte mirror。guide 側で直接編集しない |
| `binding.json` | guide-doc-generator | guide の consumer だけを持つ plugin-local overlay。上流 binding の複製ではない |

vendor manifest は source・target・digest を一組として検査する。途中までコピーした状態を
正常扱いしない。guide の実行時は slide-report-generator を読まず、同梱された mirror と
local overlay だけで完結する。

`consumer_scope` は guide の owner skill 配下にある agent 実体と consumer の閉包を宣言する。
上流 validator は byte parity 対象外の local overlay も、共通 schema・177原則分類・prompt
delivery まで通常実行で検査する。

## Consumer 共通契約

consumer の prompt は次の marker とこの README への参照だけを持つ。選択条件・必須原則・
共通注意を prompt へ複製しない。

```md
<!-- deck-principles-consumer: <consumer-id>; run-by: <agent|orchestrator> -->
```

- `run-by: agent`: 作業開始前に selector を 1 回実行し、返却された selection envelope を判断軸へ加える。
- `run-by: orchestrator`: 起動側が selector を実行し、selection envelope を task brief で渡す。無ければ開始せず差し戻す。
- カタログ全体は直接読まない。既存の plugin 固有 reference を置き換えず、競合時は固有 reference を優先する。
- pt は投影・印刷の目安であり、guide HTML の実値は `assets/tokens/<theme>.json` を正本とする。

## 実行

環境変数がなくても、selector は `__file__` と同居する `assets/deck-principles/` を安全な
fallback として解決する。`SRG_ROOT` が同時に設定されていても、明示的な
`DECK_PRINCIPLES_DIR` 以外の sibling plugin を同梱資産より優先しない。

```bash
python3 plugins/guide-doc-generator/scripts/select-deck-principles.py --consumer handout-content-architect --format json
python3 plugins/guide-doc-generator/scripts/select-deck-principles.py --consumer handout-readability-reviewer --format json
```

原則を変えるときは上流正本を更新して vendor manifest の同期・検査を実行する。
guide 固有の consumer 配線を変えるときだけ `binding.json` を更新し、binding schema と
focused test を通す。
