# jp-web-design モードB「Pop・親しみ」(vendored)

出所: jp-web-design skill の references/mode-b-pop.md。guide-doc-generator は実行時に
plugin の外を読まないため (R10 自己完結)、採用した規範だけをここへ複製した。
複製した時点: 2026-08-17。以降 jp-web-design 側が変わっても、この plugin の
規範はこのファイルが正本である。

このファイルは「デザイン言語の考え方」の正本であって、テーマの実値の正本では
ない。実値は `assets/tokens/<theme>.json` (スキーマ owner: C11) にある。

## 1. なぜモードB を採る

guide-doc-generator が作るのは初心者・非エンジニア向けの配布資料である。読み手に
「触ってよい」と思わせる必要がある一方、業務資料としての正確さは落とせない。
モードB は「色のトーン・面・丸み・太さ・かわいさ」だけを親しみ側へ振り、
組版禁則・数値表記・アクセシビリティ・情報設計の規律はモードA と共通に保つ。
この切り分けがそのまま guide-doc-generator の要件に合う。

## 2. カラー: パステル変換

指定されたアクセント色をそのまま使わず、明度を上げ彩度を中庸に残した淡色トーン
へ変換する。白っぽすぎると事務的になり、鮮やかすぎると玩具になる。

| 指定の系統 | 面・CTA に使う淡色の方向 | 文字・リンクに使う deep の方向 |
|---|---|---|
| 青・水色 | 淡いスカイ | 落ち着いた青 |
| 赤 | コーラル | 沈んだ赤 |
| 緑 | ミント | 深い緑 |
| 紫 | ラベンダー | 沈んだ紫 |
| ピンク | ベビーピンク | 沈んだピンク |
| 黄・オレンジ | アプリコット | 沈んだ橙 |

具体的な色値をここへ書かない。テーマごとの実値は `assets/tokens/<theme>.json`
が持ち、そこから 4 段階が `:root` へ展開される。

- 明度 4 段階の役割: ブライト = CTA とトグル ON、パステル = 面、soft = 選択状態と
  チップとリング、deep = 文字とリンクと線画アイコン。
- deep は面に使わない。1 か所だけ濃いと浮く。
- アクセントが背景になる要素の前景は白にする。
- 差し色 1 つ、強調は 2 か所まで、色相は 3 つまで。

## 3. 「これをすればいいんだ」の構造

モードB の本質は丸さではなく迷いの少なさである。

1. 1 画面 1 アクション。並列の選択肢を冒頭に置かない。
2. 開いた瞬間に価値が見える。説明より先に本題を置く。
3. 最頻タスクの手数を数える。増えるなら既定値で先回りする。
4. 説明文で埋めない。機能は線画アイコンと体言止め 1 行で示す。
5. 選択は自由入力よりチップの選択にする。選択状態は soft 色。

## 4. かわいらしさの作り方 (幼くならない範囲)

| 要素 | 作法 |
|---|---|
| 見出しの遊び | 主役級の見出しだけに、わずかな傾きか soft 色の波線下線 |
| 注釈 | ループする細い矢印と短い一言。矢印は線画アイコンとして sprite に入れる |
| カード | 罫線は淡く、角丸は大きく。メタファーアイコンを機械的に置かない |
| 角と影 | 影はごく淡く低く。色地が面を浮かせるので基本は不要 |
| 文字 | 操作要素は太字。ただし一文は短く |
| 遊びの上限 | 傾き・波線・ループ矢印は 1 画面に 2 から 3 つまで |
| 絵文字 | 使わない。親しみは色と形と文体で出す |

## 5. モードB でも不変の規律

- 視覚的主役は 1 画面 1 つ。全部を目立たせれば視線誘導は死ぬ。
- 数値・単位・区切りの規律、フォーカス可視化、タップ領域の確保は不変。
- 黒背景と黒 CTA を使わない。バウンスを使わない。
- `prefers-reduced-motion: reduce` への対応は不変。入場アニメーションは
  そこで無効化する。

## 6. guide-doc-generator が採らなかったもの

vendoring 元にはあるが、この plugin では採用しない。

- マスコット画像の使用ルール: 配布資料の題材と無関係なキャラクターを置かない。
  plugin 同梱のマスコット資産の扱いは C11 の write_scope に属する。
- ネイティブフォームコントロールの自前描画: 生成物はフォームを持たない。
- 完了画面の演出: 単一 HTML の資料に完了画面が無い。
