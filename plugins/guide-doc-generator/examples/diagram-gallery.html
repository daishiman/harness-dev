図解の表現と読みやすさ

申請から承認までの流れ案Aと案Bの比較組織の階層改善のサイクル施策の位置づけ自前で作るか既製品を使うか手作業から自動化へ倉庫にたとえる回答までの時間条件で承認先を分ける依頼と結果の受け渡し準備から公開までの節目確認と実装を並行する同じ単位で件数を比べる週ごとの変化を見る対象を段階的に絞る短い手順を順番に読む独立した要点を並べる同じ観点で比べる関係から表現を探す

文章の関係を、読める図へ

HTMLは図の種類ではなく、資料の出力形式・描画方法です。短い手順や比較はHTML/CSS、接続線や座標を追う図はSVG、専用の記法は描画済み素材を選べます。

関係から表現を探し、実例へ進む

以下の数値・日程は表現確認用の架空データです。

1. 申請から承認までの流れ

この表現に渡すデータ

steps 2-6 件。各件 {label, note?}

2. 案Aと案Bの比較

この表現に渡すデータ

axes 1-6 件・items 2-4 件・cells は items×axes の全マス

3. 組織の階層

この表現に渡すデータ

root {label} と children 1-5 件。深さは root を第1層として 3 まで

4. 改善のサイクル

この表現に渡すデータ

steps 3-6 件。各件 {label}

5. 施策の位置づけ

この表現に渡すデータ

x_axis/y_axis の {low, high} と items 1-8 件。各件 {label, x, y} は 0.0-1.0

6. 自前で作るか既製品を使うか

この表現に渡すデータ

left/right の {label, bullets 1-5 件}

7. 手作業から自動化へ

この表現に渡すデータ

before/after の {label, bullets 0-4 件} と arrow_label?

8. 倉庫にたとえる

この表現に渡すデータ

known/target の {label, note?} と pairs 1-4 件 {from, to}

9. 回答までの時間

この表現に渡すデータ

{value, unit?, caption, sub?}

10. 条件で承認先を分ける

この表現に渡すデータ

nodes[{id,label,row:0..7,col:0..2,shape?:box|decision}], edges[{from,to,label?}]

11. 依頼と結果の受け渡し

この表現に渡すデータ

actors[string] 2-4, messages[{from,to,label}] 1-10。配列順が時系列

12. 準備から公開までの節目

この表現に渡すデータ

events[{date:string,label}] 2-10。等間隔の出来事列で期間の長さは表さない

13. 確認と実装を並行する

この表現に渡すデータ

tasks[{label,start:YYYY-MM-DD,end:YYYY-MM-DD}] 1-10。終了日を含む

14. 同じ単位で件数を比べる

この表現に渡すデータ

unit:string, items[{label,value:有限非負数}] 1-10。棒の起点は0

15. 週ごとの変化を見る

この表現に渡すデータ

unit:string, items[{label,value:有限非負数}] 2-10。等間隔系列に限る

16. 対象を段階的に絞る

この表現に渡すデータ

levels[{label}] 2-6, direction:narrowing|widening|equal。面積は数量ではない
