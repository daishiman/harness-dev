# Hyogo AI preset の案件知見

**この preset を使う案件でだけ読む。**（`init --preset hyogo-ai`。別名 `hyogo`）汎用の規則・担当・指針はこのファイルを参照しない。ここにある値を他の案件へ当てはめない。

ここにある値は過去案件の記録である。今回の利用者の回答と支給資料で確かめてから使う（[E2](../../essence.json)）。v13 改訂で利用者が出した個別条件は [v13-feedback](v13-feedback.md) に分けてある。汎用の原則はそれぞれ [design-rules](../../design-rules.md) の該当節を正本とし、ここでは案件の具体例だけを書く。

## 初期案の優先度

HyogoAI を選んだときの初期案として使う。一般の案件へは強制しない。

1. 主題の 2 句の主従と、問いを並べる順（会社の導入の悩み → 導入したが使えない悩み → 個人の AI 活用）は、[v13-feedback](v13-feedback.md) 冒頭の箇条を初期案にする。経営者限定を前面に出さず、会社の課題を先に示す。
2. 3 人で実例トークを行うことと 3 名の氏名を同格で示す。写真が 1 人でも、その人だけの講演に見えない構成にする。「写真の人物も 3 人のうちの 1 人」のような説明文は足さない。
3. 右上は最新の支給 HyogoAI ロゴ、左上は `AI活用交流会 vol.1` などの内容名にして、HyogoAI の表記を重ねない。開催回は今回の値を確認する。
4. 過去会場は「アスピア明石北館（明石駅周辺）」であり、「明石駅前」とは書かない。開催場所・住所・日時・料金を次回へ黙って転用しない。

## 中心軸と構図の事例

- vol.1 では、下部の登壇者・質問・日時・会場/住所・料金・注意を axisGroups（中心軸にそろえる意味群）とし、A4 縦 210mm 幅の 105mm を軸にした（見本 F07・F11）。汎用の原則は [design-rules §1](../../design-rules.md#1-紙面の中心と意味のまとまり)。
- 同梱見本の F07（左に人物、右に縦の題）と F11（左に大きな題、右に人物）は、上部の意図的な非対称の観察例である。全紙面を中央揃えにする根拠にはしない。

## 文字量

- 本文の約 225 字は、この案件の見本に対する目安である。全用途の上限ではない。上限の決め方は [design-rules §3](../../design-rules.md#3-情報量と意味)。

## 読者の認知の仮説

汎用の観察手順は [design-rules §11](../../design-rules.md#11-読者の認知と行動の観察)。この preset では次を仮説として使う。

- 主題の発見 → 会社の問いから自分向けと気付く → 相談できる人がいる価値を理解する → 条件 → QR。
- 観察する語: 「まずここへ。」と「ここにいる。」の両方の強さ。左上の内容名と HyogoAI ロゴが縮小像で別々に読めるか。

## 局所背景で起きやすいこと

- 背景の金模様と、金色で組んだ会社向けの問いが同化しやすい。指摘は pt 値ではなく、実際の画像領域で読めないこととして返す。v13 の具体指摘と比べる候補は [v13-feedback](v13-feedback.md#最新のf07観察課題)。比べる順序の原則は [design-rules §10](../../design-rules.md#10-局所背景の可読性とブランドの判読)。
