# 挑戦宣言と企画の作成

目的・目標・挑戦・リスク回避5理由・行うこと5つ・定期報告を会話で引き出し、vault に保存して提出用テキストを表示する入口コマンド。

`run-ubm-challenge` スキルを `Skill` ツールで起動し、その指示に従って実行する。
引数 `$ARGUMENTS` があれば挑戦の仮タイトルとして使う（欄の中身にはしない）。

- **準備**: 保存先の vault の場所を環境変数 `UBM_VAULT_ROOT` に設定しておく。未設定だと保存先が決まらないので、対話を始める前に設定を頼まれる（「現状で試す」で下書きを見るだけなら要らない）。
- **深さの選び方**: 最初に全欄が空の下書きが表示されるので、それを見て選ぶ。下書きを見るだけで終えるなら「現状で試す」、北原さんの考え方を添えずに問いだけで埋めるなら「軽微」、
  北原さんの考え方を項目ごとに1つまで添えながら進めたいなら「標準」、2つまで添えてほしいなら「詳細」（項目はリスク回避の理由5つを別々に数える）。
