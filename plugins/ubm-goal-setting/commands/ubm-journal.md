# 日次ジャーナル作成

その日やったことを会話で振り返り、`02_Configs/Daily/{YYYY-MM-DD}.md` へ構造化された
ジャーナルを生成する入口コマンド。通し番号は Daily 配下の既存ジャーナルの最大値から自動で +1 される（前回ファイル+1 ではない。欠番があっても番号は重複しない）。

## 実行

`run-ubm-journal` スキルを Skill ツールで起動し、その指示に従って実行する。

- 引数 `$ARGUMENTS` に `YYYY-MM-DD` が指定されていればその日を対象日にする。
- 引数がなければ今日を対象日にする（ファイル名の日付＝見出しの日付＝振り返る日）。

## 引数

- `YYYY-MM-DD`: 振り返る対象日を明示する（前日分を書く場合など）
- 引数なし: 今日分を作成する

## 会話の進め方（スキル側で強制）

- チェックリストを読み上げない。「今日は何をやりましたか？」から自然に始める。
- 1ターン1〜2問でテンポよく進める。
- 事実 → 気づき → 次の打ち手 の順で掘る。最初から改善案を聞かない。
- 固有名詞・数値・時刻は必ず拾う。「打ち合わせをした」で止めず、誰と・何時から・何が決まったかまで確認する。
- 目標4階層と残日数は週報・月報・期報から自動で埋まるので、ユーザーには確認しない。
