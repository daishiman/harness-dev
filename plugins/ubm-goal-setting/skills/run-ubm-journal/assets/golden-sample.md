## 【行動のジャーナル】

### 現状を確認する

- 8/15のAI勉強会・質問会を13:00〜16:00で実施し、終了後のお礼メールまで完了した。
- 8/16のUBM兵庫支部会の打ち合わせに参加し、北原さんと直接話した。
- 依頼アプリ制作は週内で4日実施でき、前週の2日から改善した。
- 8/27勉強会の告知・チラシは未着手のまま週をまたいだ。
- Gridノートは朝の作業開始前に書けた日が5日、書かないまま始めた日が2日。
- ジャーナルは散歩の直後に着手し、22:10から書き始めた。
- SNSは勉強会の様子をXへ1件投稿した。noteの下書きは未着手。

### 効果性を評価する

- 相手との約束がある行動は期日内に完了しており、提出先の有無が実行率を分けている構造は変わっていない。
- 依頼アプリ制作が改善したのは、先に予定として時間を押さえたためで、意志の問題ではなかった。
- 8/27勉強会の準備は「前倒しの余力」が作れておらず、直前作業に戻るリスクが残っている。

### 更に良くする方法はないか

- 8/27勉強会の告知・チラシを、今週の最初の2日に30分ブロックで先に押さえる。
- ひとりで作る資料には提出先と提出日を1件ずつ書き、人との約束に変換する。
- 依頼アプリ制作の30分ブロックはカレンダー上に先に固定し、空き時間を後から探さない。

## 【時間のジャーナル】

### 現状を確認する

- 8/15は勉強会で180分、8/16は打ち合わせで夜の時間を使い、後半に予定が固まっていた。
- 30分ブロックは予定がある日ほど機能し、予定が空いている日に崩れた。
- 自宅作業の日は漫画・YouTubeへ逃げる時間が発生した（予定外の視聴45分）。
- 就寝は23:40。23時目標に対して40分の超過。

### 効果性を評価する

- 悪循環の起点は集中力ではなく作業環境と体の固まりにあり、外で作業する日は歯止めが効いている。
- 予定が後半に集中する週は、前半に準備を寄せられるかで全体の余裕が決まる。

### 更に良くする方法はないか

- 予定が空いている日ほど、朝のうちに30分ブロックを3本カレンダーへ置く。
- コワーキングスペースなど外での作業日を週の前半に配置する。
- 作業の合間にストレッチを挟み、固まったまま続けない。

## 【お金のジャーナル】

### 現状を確認する

- 今期の売上目標1,000,000に対し、累計実績は410,000。
- 8月の確定内訳250,000（ティアマインド200,000＋青木さん50,000）は合意済みだが書面提示は未完了。
- 固定費300,000に対し-50,000の構造は変わっていない。

### 効果性を評価する

- 週次で入金額を追わず確定内訳の合意状況を追う運用は、入金が月末に寄る実態と噛み合っている。
- 不足50,000を埋める手段は個人向けAIコンサルの稼働のみに絞られており、依頼アプリの進捗がそのまま金額構造を動かす。

### 更に良くする方法はないか

- 青木さんへの50,000は書面提示まで進め、8月の入金を月末締めで確定させる。
- 依頼アプリの稼働を最優先にし、実績1件で構造そのものを動かす。
- Notion案件台帳に金額・期間・次アクションを入れ、1箇所で見える状態を維持する。
