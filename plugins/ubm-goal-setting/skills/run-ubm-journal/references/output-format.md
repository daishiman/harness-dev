# 日次ジャーナル 出力フォーマット正本

`validate-journal-output.py` はこのファイルの骨格定義に基づいて検査する。見出し文字列を変更する
場合は、このファイル・バリデータ・`assets/golden-sample.md` の3点を同時に更新する。

## 保存先とファイル名

- パス: `$UBM_VAULT_ROOT/02_Configs/Daily/{YYYY-MM-DD}.md`
- `{YYYY-MM-DD}` は **振り返る対象日**。ファイル名の日付・見出しの日付・振り返る日は常に一致させる。
- 既に同日ファイルがある場合は通し番号を維持したまま更新する（採番を飛ばさない）。

## 通し番号

- `build-journal-context.py` が `Daily/` 全ファイルの `# No.<数字> - ジャーナル（YYYY-MM-DD）` を
  走査し、最大値 +1 を返す。LLM は番号を推測せず、必ずこのスクリプトの `journal_number` を使う。
- 同日ファイルが既に番号を持つ場合はその番号を再利用する（`is_regeneration: true`）。

## 骨格（この順序で出力する）

```markdown
---
tags:
  - review
---
# 人生の究極の目標

![[人生の究極の目的#🎯 究極の人生の目的]]

# No.{番号} - ジャーナル（{YYYY-MM-DD}）

## 人生の究極目的
## 目標
### 1年目標
### 3ヶ月目標
### 1ヶ月目標
### 1週間目標
## 感謝
## 【禁止事項】
## 【タスク】
### 【{分類}】
## 【行動のジャーナル】
### 現状を確認する
### 効果性を評価する
### 更に良くする方法はないか
## 【時間のジャーナル】
### 現状を確認する
### 効果性を評価する
### 更に良くする方法はないか
## 【お金のジャーナル】
### 現状を確認する
### 効果性を評価する
### 更に良くする方法はないか

# フェーズ別 課題チェックシート

## ◇【0→1】
## ◇【1→10】
## ◇【10→100】
```

## 各ブロックの記述規則

| ブロック | データ源 | 規則 |
|---|---|---|
| 人生の究極目的 | 前回ジャーナルから継承 | 箇条書き1件。ユーザーが変更を申し出た時だけ書き換える |
| 1年目標 | 前回ジャーナルから継承 | 期間はレポートに対応物が無いので継承。期間終了時は「残り：0日（{終了日}で満了・超過{N}日／新サイクルの1年目標は要設定）」 |
| 3ヶ月目標 | 月報（２ヶ月）（`## 【2ヶ月の目標】`） | 期間は**レポート側が正**。前回ジャーナルと食い違ったら目標本文を新期間の内容へ更新する |
| 1ヶ月目標 | 月報（`## 【1ヶ月の目標】`） | 同上 |
| 1週間目標 | 週報（`## 【1週間の目標】`） | 同上。対象日を含む週報が無ければ直近週報を使い、残りは「0日（期間終了・次週分の週報は未作成）」 |
| 感謝 | 対話 | `- {名前}: {何をしてもらったか}` 形式で3件を目安。「自分自身」も可 |
| 【禁止事項】 | 対話（前回ジャーナル＋週報の判断基準を候補提示） | やらないことを行動レベルで。1件以上必須 |
| 【タスク】 | 対話（週報の当日タスク・成果目標を候補提示） | `### 【{分類}】` で括る。分類はその日の実態に合わせて命名する（固定リストではない） |
| 行動/時間/お金のジャーナル | 対話 | 各3小節すべてに箇条書き1件以上。「現状＝事実」「効果性＝解釈」「更に良く＝次の打ち手」を混ぜない |
| フェーズ別課題チェックシート | 前回ジャーナルから継承 | チェック状態を引き継ぎ、対話で変化があった項目だけ更新する |

## 目標の期間・残日数

- 期間表記は `YYYY-MM-DD〜YYYY-MM-DD`（半角ハイフン区切り・全角チルダ）。
- 残日数は `build-journal-context.py` の `days_remaining` をそのまま使う（対象日から終了日までの日数）。
- `expired: true` の場合は `0日（期間終了）` を基本形とし、`days_overdue` があれば補足を添える。

## 文章スタイル

- 数値は半角（「25万円」ではなく `250,000`）。
- 目標本文は達成済みの言い切り（過去形）で書く。北原さん式ゴールセッティングの表記に合わせる。
- ジャーナル本文は、ユーザーの発言を要約しすぎず、事実・固有名詞・数値を落とさずに箇条書きへ分解する。
- 冗長な言い回し（「〜という感じで」「〜だと思っています」）は削り、1項目1事実にする。

## バリデーション

```bash
python3 scripts/validate-journal-output.py \
  --file "$UBM_VAULT_ROOT/02_Configs/Daily/{YYYY-MM-DD}.md" \
  --expected-number {journal_number} --expected-date {YYYY-MM-DD}
```

違反コード: `F*`=ファイル名/見出し整合 / `S01`=骨格の存在と順序 / `G*`=目標4階層 /
`C*`=中身が空 / `J*`=3ジャーナルの小節 / `P*`=フェーズ別チェック / `X01`=未置換プレースホルダ。
