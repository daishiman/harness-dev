# チェックシート 正本

ジャーナル末尾の `# チェックシート` ブロック（`# ① 事業フェーズチェックシート（UBM）`・
`# ② 人生資金チェックシート`・`# ③ チェックシート（UBM）`）へ出力する項目の正本。
文言の出典は vault の `02_Configs/Templates/Daily.md`（利用者が 2026-10-30 に更新した版）。
見出しや設問を変える手順は `output-format.md` 冒頭の変更契約が正本。

## 出力規則

- `build-journal-context.py` が返す `checklists.block` を、`## 【お金のジャーナル】` の後ろへそのまま貼る。
  対話（Phase1-3）では項目を読み上げず、整形（Phase4）で器として出す。省略・要約・抜粋しない。
- `checklists.block` は 3 シートとも前回ジャーナルから継承した状態で渡される。整形で変えてよいのは、
  対話で利用者が変化を申し出た項目の `[ ]` / `[x]` と、②の金額欄（`：　　円`）・④の表の中身だけ。
- 各シートの出所は `checklists.sheets.<key>.source` に出る。
  - `previous_journal`: 前回ジャーナルの同じシートをそのまま継承した。
  - `migrated_from_legacy`: 前回が旧形式（`# フェーズ別 課題チェックシート` / `# 原理原則 チェックシート`）だった。
    テンプレートの項目のうち、チェック行の文言（空白を除く）が旧形式と同じものだけ `[x]` を移した。
    同じ文言が何度か出るときは、出てきた順に対応させる。文言が変わった項目は未チェックで始まる。
  - `template`: 前回ジャーナルに材料が無いので、下のテンプレートを未チェックで使った。
- 旧形式の `# フェーズ別 課題チェックシート` と `# 原理原則 チェックシート` は出力しない
  （残っていると validate-journal-output が S02 で止める）。
- シートの間の `---` は `checklists.block` が持っている。③の「右肩上がりになっていますか？」の中にある
  `-------` と「必要に応じて↓」は項目の一部なので、消さずに残す。
- 注記（`※…`・`⇧…`）は字下げも含めてそのまま残す。
- 出典の `振り返りチェック` の見出しは頭に電球の絵文字が付いていたが、出力に絵文字を使わない決まりに合わせて
  外し、`### 振り返りチェック` にしてある。
