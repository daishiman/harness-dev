# 原理原則 チェックシート 正本

北原さん式の原理原則チェックシート。日次ジャーナルの末尾に **毎回必ず出力する** 固定ブロック。

`validate-journal-output.py` の K01/K02 はこのファイルの見出し定義に基づいて検査する。
設問を増減・改名する場合は、このファイル・`output-format.md`・バリデータ・
`assets/golden-sample.md`・`tests/test_validate_journal_output.py` を同時に更新する。

## 出力ルール

- 出力位置: `# フェーズ別 課題チェックシート` の **後**、ファイル末尾。レベル1見出しで置く。
- チェック状態は **前回ジャーナルから継承** する（`build-journal-context.py` の
  `previous_journal.principle_checklist`）。前回が無い初回は、下のテンプレを全て未チェックで出す。
- 対話で状態が変わった項目だけを更新する。ユーザーが触れなかった項目は前回の状態を保つ。
- 設問の文言・順序・階層は書き換えない。ジャーナル本文と違い、ここは器そのものが正本。
- 対話中にこのシートを読み上げない。ジャーナル生成時に器として出力するだけでよい。

## テンプレ本体（この内容をそのまま出力する）

```markdown
# 原理原則 チェックシート

## ◇ 毎月の利益と口座残高の状況がわかるようになっていますか？

（※以下のどの状態ですか？）

- [ ] 月末締め翌月15日までに集計が上がる状態ですか？
- [ ] 月末締め翌月7日までに集計が上がる状態ですか？
- [ ] 月末締め翌月5日までに集計が上がる状態ですか？
- [ ] 月末締め翌月1日までに集計が上がる状態ですか？
- [ ] 1日単位で集計が上がる状態ですか？

> ※現状のお金の動きがわからない人は毎日見て必ず把握してください

## ◇ 右肩上がりになっていますか？

- [ ] 会社（事業）の口座残高
- [ ] 個人の口座残高

―――（必要に応じて）―――

- [ ] 事業や部署ごとの口座残高
- [ ] 社員や課員の口座残高
- [ ] 家族の口座残高

## ◇ 原理原則を学び見直す状態は作れていますか？

- [ ] 24時間以内にすべての通知を"既読"にできていますか？
- [ ] 24時間以内に返信ができていますか？
- [ ] 月初に1ヵ月を振り返り月報を書く時間を確保していますか？
- [ ] 月に1回以上 家や会社や拠点の中を見直し改善する時間は取れていますか？
- [ ] 月に1回以上 UBMの会場に来れる状態ですか？
- [ ] 次回のUBM会場に来る日は決まっていますか？
    - ⇧必ず決めて帰宅してください

## ◇ 決めた括りの人が増え、歴史の共有ができていますか？（1）

### メンターを決め学びを共有してもらっていますか？

- [ ] メンターを決め学びを共有してもらっていますか？
    - [ ] 近くで学べる関係ですか？
    - [ ] 次回の会う日は決まっていますか？
    - [ ] 提案ができる関係ですか？
    - [ ] 力を借りられる関係ですか？

### 可愛がる人（教え子）を決め学びの共有をしていますか？

- [ ] 可愛がる人（教え子）を決め学びの共有をしていますか？
    - [ ] 月に1回以上 勉強会を社内や主催（副主催）や講師として開催できていますか？
    - [ ] 教え子の人数は減っていませんか？
    - [ ] 教え子の人数が増えていますか？
    - [ ] 教え子の富が増えていますか？
    - [ ] 教え子に富を共有できていますか？

### 可愛がってくださる人のお手伝いや徳積みのご提案ができていますか？

- [ ] 可愛がってくださる人のお手伝いや徳積みのご提案ができていますか？
    - [ ] 次回の会う日は決まっていますか？
    - [ ] お仕事の提案はできる関係ですか？
    - [ ] 力を借りられる関係ですか？
    - [ ] 可愛がってくださる方からのお仕事はいただけていますか？

## ◇ 決めた括りの人が増え、歴史の共有ができていますか？（2）

- [ ] 共に生きる横並びの生涯メンバーは増えていますか？ or 離れていませんか？
    - [ ] メンバーは減っていませんか？
    - [ ] メンバーは増えましたか？
    - [ ] メンバーとの事業や会社の富は増えましたか？
        - ※口座、資産、その他

## ◇ 支出は前回から下げられましたか or 利益率は上げられましたか？

- [ ] 会社（事業）の支出を減らせましたか？利益率は上げられましたか？
- [ ] 個人（家族）の支出を減らせましたか？利益率は上げられましたか？

> ※食費や家賃、宿泊費や交通費すらも減らせる視点を身に付けていきましょう

## ◇ 今の行動を積み上げた先に上記のチェックが全て埋まる行動になっていますか？

- [ ] チェックが全て埋まる、これからの行動を解説することができますか？
- [ ] チェックが全て埋まる、アクションプランが構築できていますか？
- [ ] チェックが全て埋まる、年間計画がスケジュールに反映されていますか？
- [ ] チェックが全て埋まる、スケジュールを実行できていますか？
- [ ] チェックが全て埋まる、スケジュールに改善する時間が全てのメンバーと取れていますか？

## ◇ 川上に繋がる描きができスケジュールが配置されていますか？

- [ ] 今の行動を重ねていくことで川上に繋がるようにプラン設計できていますか？
    - ※例）美容師 → 経営者 → 同業者のサポート → 事業本部 or 薬剤開発 → 不動産　等々

## ◇ 次回、UBMで原理原則を学び確認する日は入っていますか？

- [ ] 次回のUBMの日程は決まっていますか？
    - [ ] 3ヵ月に1回の年間スケジュールに入っていますか？
    - [ ] 1ヵ月に1回の年間スケジュールに入っていますか？
- [ ] 次回の支部会の日程は決まっていますか？
    - [ ] 3ヵ月に1回の年間スケジュールに入っていますか？
    - [ ] 1ヵ月に1回の年間スケジュールに入っていますか？

## ◇ あなたと共に同じ学びを共有するメンバーは増えていますか？

- [ ] 次回のUBM合宿にあなたの横並びや教え子や課員として一緒に来るメンバーは居ますか？
- [ ] 次回の支部会にあなたの横並びや教え子や課員として一緒に来るメンバーは居ますか？

> ※大切な人とは家族も含めてできる限り同じ学びを共有していくこと

## ◇ あなたの教え子からリーダーが生まれていますか？

- [ ] あなたは主催や副主催としての勉強会は開催できていますか？
- [ ] あなたの勉強会に参加したメンバーの事業は伸びていますか？
- [ ] 勉強会のメンバーからあなたと 一緒 or 元 で事業やイベントは開催できていますか？
- [ ] あなたの事業を手伝ってくれるリーダーと1つの事業を一緒に作れていますか？

> ※例）北原は№1.2.3の育成排出し共に生き多角化できるメンバーが増え続けています
```
