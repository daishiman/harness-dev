# ゴールデンサンプル: 週報（1週間の目標・統一ハイブリッド）

出力フォーマットの「完成した状態」の例。output-formatter や LLM が出力する際の品質基準として参照する。

**これは架空のサンプルであり、実在のクライアント情報・実数値ではない。**
本人の名前は `Xさん`、相手の名前は `Aさん` `Bさん` `Cさん` のプレースホルダで書く。実在しそうな人名を手本に置くと、
LLM が書式ではなく名前まで模倣し、読み手も「これは自分のどの案件のことか」と照合を強いられる。

**このファイルを手本のファイル名のまま `validate-goal-output.py` に当てると rc=1 になる。** ファイル名検査2件（`UBM - {1,2,3}-` で始まること／ファイル名に `YYYY-MM-DD〜YYYY-MM-DD` があること）が、手本のファイル名では必ず落ちるため。**構造・内容の FAIL が0件であることが手本の合格条件**で、テストは `UBM - 1-週報 2026-06-29〜2026-07-05.md` の名前の一時ファイルへ写して rc=0 を確かめる。照合側の `validate-goal-linkage.py` はファイル名を見ないので、こちらはこのファイルのまま rc=0 が合格条件。

統一ハイブリッド構造で出力する。ゾーンA（ロールアップ用ヘッダー＝準静的・前週実績）とゾーンB（今週の実行＝毎日見るチェックリスト群）を `---` で区切る。語彙はアカデミー基準。
