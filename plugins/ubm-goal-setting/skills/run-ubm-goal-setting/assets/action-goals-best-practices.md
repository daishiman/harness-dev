# 行動目標 ベストプラクティス

過去の目標設定ファイルから抽出した「良い行動目標」のパターン集。
目標設定時にこの基準で具体性を担保する。

---

## 売上以外の成果目標のフォーマット（週報・月報・期報 共通）

成果目標は **売上目標から逆算して置く**。各項目に「この成果が売上をいくら動かすか」を数値で持たせ、売上と成果を線でつなぐ。

### フォーマット定義

**1項目=2行**（正本は `references/output-formats.md`）。

```
- [相手/項目]：[先方判断・結果の状態]　期日[M/D]
  → 売上貢献：[単価] × [件数] = [貢献額]
```

貢献額には **式** または **括弧の根拠** のいずれかが必ず随伴する。`150000` という数字だけでは、それが正しいかを後から誰も検算できないため、単価と件数を分けて残す。単価×件数の形にできないもの（値引き後の一括見積など）は式を省いてよいが、その場合も `→ 売上貢献：150000（値引き後の一括見積）` と根拠を括弧で添える。

### 実例

```
- Aさん：研修の継続合意1件　期日4/15
  → 売上貢献：75000 × 1 = 75000

- Bさん：単価合意1件　期日4/2
  → 売上貢献：80000 × 1 = 80000

- Cさん：月額顧問の成約1件　期日4/2
  → 売上貢献：50000 × 1 = 50000

- Dさん：提案の受諾1件　期日4/10
  → 売上貢献：150000（値引き後の一括見積）

- Eさん：追加ライセンスの発注3件　期日4/15
  → 売上貢献：40000 × 3 = 120000

- AI質問会勉強会：参加者5名以上　期日4/18
  → 売上貢献：0（5月に体験診断2件・300000 の見込み）
```

Cさんの月額顧問が `50000 × 1` なのは、**その期間に実際に売上として立つ分だけを計上する**ため。月額5万円の顧問契約で今週の売上に立つのは初月の 50000 であって、3ヶ月分の 150000 ではない。式の件数に期間単位（`ヶ月`／`年`）を掛けない。期間をまたぐ分は次の期間の成果目標として立て直すか、`→ 売上貢献：0（8月に 100000 の見込み）` の形で見通しとして書く。

### 記述ルール

| ルール | OK例 | NG例 |
|--------|------|------|
| 貢献額は式か括弧の根拠つき | `→ 売上貢献：80000 × 1 = 80000` ／ `→ 売上貢献：150000（値引き後の一括見積）` | `→ 売上貢献：150000`（裸の数字） |
| その期間に立つ分だけ計上 | 月額5万の顧問の今週分 `→ 売上貢献：50000 × 1 = 50000` | `→ 売上貢献：50000 × 3 = 150000`（3ヶ月分を今週に計上） |
| 式の左辺の積と右辺は一致 | `40000 × 3 = 120000` | `40000 × 3 = 150000` |
| 売上に乗らないものは0＋時期と金額 | `→ 売上貢献：0（5月に 300000 の見込み）` | `→ 売上貢献：0`／`0（母集団のため）` |
| 数値化必須 | 成約数12件　期日6/30 | 前月の成約数を上回ります |
| 期日必須 | 単価合意1件　期日4/2 | 単価合意を目指す |
| 相手名は固有名詞 | Bさん：... | クライアント：... |
| 実行完了型は置かない | Aさん：研修の継続合意1件 | Aさん：研修実施1回 |
| 合計が売上目標に届く | 貢献合計 = 売上目標 | 貢献合計 < 売上目標のまま放置 |
| 1項目1成果（`・` 禁止） | Bさん：業務委託の開始1件　期日4/2 | Bさん：単価合意1件・業務委託開始1件　期日4/2 |
| 短く書く（成果5件・50字／行動8件・60字まで） | Bさん：提案の受諾1件　期日7/3 | Bさん：体験診断を経たうえでの提案内容への受諾1件　期日7/3 |

※ 表内の例は紙幅の都合で1行に畳んである。実際の出力は上の「フォーマット定義」どおり **1項目=2行**（`→ 売上貢献：` は2行目）。

### 実行完了型を置かない（最重要）

**実行した時点で達成になってしまうもの**は成果目標ではない。それは行動であり、やって当たり前のこととして扱う。

北原さん:「実行したら完了する目標は、もう置きません。実行したら成果につながって、売上につながる。そこまで降りてくる目標だけにします」

| ✗ 成果目標に書いてはいけない | ✓ 成果目標として置き直す |
|---|---|
| 勉強会を月4回開催する | 勉強会からの体験診断の申込3件　→ 売上貢献：0（翌月に 300000 の見込み） |
| 研修実施1回 | 研修後の継続合意1件　→ 売上貢献：75000 × 1 = 75000 |
| アカデミーに参加する | （目標に置かない。当たり前の土台として行動目標の `### → （土台）` グループへ） |
| 自主開催1回 | 参加者5名以上　→ 売上貢献：0（翌月に 200000 の見込み） |
| 提案書を1件提出する | 提案の受諾1件　→ 売上貢献：150000（値引き後の一括見積） |

### シンプルに書く（1項目=1つのこと）

複雑な目標・長い文の目標は、自分で自分の目標を複雑にし、結局動けなくなる。**短くまとめるのではなく、置き場所を変える**のが原則。

| 上限 | 対象 |
|---|---|
| 5件・1項目50字 | 成果目標（`→ 売上貢献` の前まで） |
| 8件・1項目60字 | 行動目標（1行目・期日込み） |

- 2つのことが入ったら **2件に割る**
  - ✗ 「火曜にBさんの体験診断1件を実施し、当日中に提案ドラフト1件を共有する」
  - ✓ 「Bさんの体験診断を実施する　期日6/30」＋「Bさんへ提案ドラフトを共有する　期日6/30」
- 対象リスト・理由・注意点は **注記行へ移す**
  - ✗ 「個別メッセージを平日は毎日4件送る（対象: 過去接点のある製造業の経営者。朝9時の最初のタスクに固定）」
  - ✓ 「個別メッセージを平日毎日4件送る　期日毎日」＋ 次行 `→ 【考え】朝9時の最初のタスクに固定し、先送りの余地をなくす`
- 上限は逸脱の検出線であり、狙う長さではない。手本は成果 21〜28字・行動 25〜30字（`assets/golden-sample-weekly.md`）

### 注記

> 上の【今月の売上目標】から逆算し、前月の未達に対する行動変化を踏まえた上で、あなたが約束する売上以外の成果目標（先方判断・期日・売上貢献額）を **1項目=2行** で数値化して記載すること。貢献額は式（`単価 × 件数 = 貢献額`）または括弧の根拠つきで、その月に実際に立つ分だけを計上すること

## 週報の行動目標パターン

週報の行動目標は、それが支える成果目標ごとに `### → {成果目標名}：{要約}（{貢献額}円）` の見出しでグループ化し、配下に `- [ ]` を並べる。見出しの金額は成果目標の貢献額と一致させる。貢献額の大きいグループを上に置く並び順は推奨（優先順位がそのまま見える）。以下は1行1行の書き方の例で、実際はこのグループ見出しの配下に置く。

### 良い例（実際の過去ファイルから抽出）

```
* Aさんとの打ち合わせを実施し、4月の関東出張時の対面候補日を打診する
* 2026-03-24にBさん、Cさんとの打ち合わせを実施し、ヒアリング内容をもとに価値提供できる内容を共有する
* Dさん経由案件は、日程確定または次回化を進める
* Eさんとの接点は、初回顔合わせの日程化または面談実施を進める
```

### パターン分析

| 要素 | 具体例 | 必須/推奨 |
|------|--------|-----------|
| **誰に** | Aさん、Bさん | 必須（固有名詞） |
| **何を** | 打ち合わせを実施、候補日を打診 | 必須（動詞で終わる） |
| **いつまでに** | 2026-03-24に、今週中に | 必須（日付または期限） |
| **成果物/ゴール** | 日程確定、次回化 | 推奨（完了条件が明確） |
| **数値** | 個別メッセージ3件/日 | 繰り返し行動には必須 |

## 月報の行動目標パターン

### 構成要素

月報の行動目標は以下の3層構造:

1. **日次行動**（毎日やること）
   - 例: 「個別メッセージを1日3件送る」
   - 例: 「毎朝9時にSNS投稿1本」

2. **週次行動**（毎週やること）
   - 例: 「週1回の勉強会を開催する」
   - 例: 「週2件の面談を実施する」

3. **期限付きタスク**（今月中にやること）
   - 例: 「3/15までにセミナー資料を完成させる」
   - 例: 「3月中にA社との契約を確定させる」

### 数字の入れ方

| パターン | 例 |
|----------|-----|
| 件数/日 | 個別メッセージ3件/日 |
| 件数/週 | 面談2件/週 |
| 件数/月 | 勉強会4回/月 |
| 累計 | 月内に新規接点20件 |
| 金額 | 契約300000円を確定 |
| 期日 | 3/15までに完了 |

---

## 期報の行動目標パターン

月報の3層構造 + 以下を追加:

4. **マイルストーン**（3ヶ月の各月の到達点）
   - 例: 「1ヶ月目: A社契約確定 + 新規2社との接点作り」
   - 例: 「2ヶ月目: 月額顧問2本を継続に載せる」
   - 例: 「3ヶ月目: 月商600000円の達成」

5. **戦略的行動**（フェーズ進行に関わる行動）
   - 例: 「商工会議所との連携体制を構築する」
   - 例: 「助成金申請を完了する」

## 「やらないこと」の書き方パターン

### 良い例（過去ファイルから抽出）

```
* 売上や案件前進に直結しない新規開発
* 細部を詰めすぎて全体の前進が止まること
* 資料を完璧にすること自体を目的にすること
* 面談や登壇を、その場限りで終わらせること
```

### パターン: 「〜すること」で統一

- 動詞の名詞化で終わる
- 具体的な行動を否定する（抽象的な「ダメなこと」ではない）
- 北原さんの「選択と集中」に基づく

---

## 判断基準の書き方パターン

### 良い例（過去ファイルから抽出）

```
今週の終わりに見るべきものは、頑張った感ではない。

* 次回の約束が増えたか
* 新しい接点が増えたか
```

### パターン: 「〜したか？」の疑問形

- Yes/No で判断できる基準
- 数値で測定可能
- 「頑張った感」を排除する視点

## 合宿アドバイスとの整合性チェック

### チェック項目

目標設定時に、直近の合宿フィードバックと以下の点で整合性を確認:

1. **方向性の一致**: 合宿で決めた事業方針と目標がズレていないか
2. **フェーズの一致**: 合宿で確認したフェーズに合った目標か
3. **具体的アドバイスの反映**: 合宿で受けたアドバイスが行動目標に落とし込まれているか
4. **前提の更新**: 合宿で覆された前提が目標に反映されているか

### チェック方法

```
直近の合宿（{{camp_date}}）で受けたアドバイス:
[合宿ファイルから抽出]

今回の目標と整合性を確認:
- 方向性: OK / 要修正
- フェーズ: OK / 要修正
- アドバイス反映: 反映済み / 未反映（具体的に何が未反映か）
```

## 品質チェックリスト

目標設定完了前に以下を確認:

- [ ] 成果目標が1項目=2行で書かれ、貢献額に式（`単価 × 件数 = 貢献額`）または括弧の根拠が付いている（裸の数字が無い）
- [ ] 貢献額が、その期間に実際に売上として立つ分だけになっている（式の件数に `ヶ月`／`年` を掛けていない）
- [ ] 行動目標に「頑張る」「意識する」「気をつける」が含まれていない
- [ ] 全ての行動目標に数値または期日が含まれている
- [ ] 固有名詞（人名・社名）が入っている（該当する場合）
- [ ] 「やらないこと」が3つ以上設定されている
- [ ] 判断基準がYes/Noで判定可能
- [ ] 直近の合宿アドバイスと方向性が一致している
- [ ] 売上目標から逆算した行動量が明記されている
- [ ] 北原さんの原則との整合性がある
