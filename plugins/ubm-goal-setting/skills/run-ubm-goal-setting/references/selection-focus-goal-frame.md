## 2. 選択と集中の5要素（共通チェック）

期間を問わず、目標が下の5要素で**1点に収束しているか**を検査する。中途半端が混ざるとブレる（PR-148）ため、複数方向が並んでいたら差し戻す。

| 要素 | 検査する問い | 差し戻し条件 |
|---|---|---|
| **人** | 師匠は1人に決まっているか。教え子（可愛がる相手）は誰か。信頼「してくれる」人か（PR-150） | 師匠が複数／教え子が未指定／「信頼している人」だけを挙げている |
| **お金** | かける前に回収の順序が立っているか（PR-149） | 先に支出する計画になっている／そもそもかけない選択肢を検討していない |
| **時間** | 掘る1点に時間が寄っているか | 複数テーマに時間が均等配分されている |
| **場所** | どこで掘るか（拠点・場・コミュニティ）が固定されているか | 場所が毎回変わる／未指定 |
| **やること** | 1点に絞られ、前期間と同じことをダラダラ繰り返していないか（PR-148） | やることが3方向以上に分散／前回と同一で組み替えがない |

**接続原則（PR-147）**: 5要素は独立の項目ではなく、1点を掘ることで繋がってくるもの。5要素それぞれに別の目標を立てさせない。

## 3. 期間別の落とし込み

5要素を毎期間まるごと問い直すと、逆にブレる。**固定するもの（人・場所）と組み替えるもの（やることの手段）を期間で分ける**（PR-148「決めた人を固定すること、あとは掘りながら組み替えていくこと」）。

### 3-1. 検査の役割分担

| 要素 | 週間（1週間） | 月間（1ヶ月） | 期報（2ヶ月） |
|---|---|---|---|
| **人**（師匠1人・教え子） | **問い直さない**。接触したか（回数・内容）だけを見る | 関係が育っているかを見る。信頼「してくれる」側になったか（PR-150） | **見直し可**。師匠・教え子の選定そのものを再評価する唯一の単位 |
| **お金** | 今週の支出がゲート（§4）を通ったかだけを見る | 回収の当てが実際に回収に至ったかを検証する | 構造として費用がかからない形になったかを見る（PR-149） |
| **時間** | 1点に何時間使ったか（実測） | 1点への配分比率が上がったか | 時間の使い方の型が定着したか |
| **場所** | **問い直さない**。決めた場所へ行った回数だけを見る | 場所での関係が増えたか | **見直し可**。掘る場所の妥当性を再評価する |
| **やること** | 決めた1点を掘れたか（実行検査） | **組み替え検査**。手段は変えてよいが、掘る場所は変えない | 1点を掘った結果、他の4要素が繋がってきたか（PR-147） |

### 3-2. 期間ごとの主目的と差し戻し条件

**週間 — 実行検査（決めたことを掘れたか）**
- 主目的: 毎日目的意識を持ち、小さな行動で整理してつなげたか（AG-049）
- 差し戻す: 師匠・場所を今週の目標で問い直している／やることが今週だけで2方向以上に分かれている／週内で成果が出ることを大きく当てにしている（PR-148「一つ一つの行動に大きくあてにしない」）
- 差し戻さない: 掘った結果が出なかったこと自体（MS-082「傷つかないと決める」を優先し、次に掘る場所の特定へ戻す）

**月間 — 接続検査（繋がってきたか・手段を組み替えるか）**
- 主目的: 1点を掘ることで人・お金・時間・場所・やることが繋がり始めているか（PR-147）
- 組み替えてよいもの: やることの**手段**（声のかけ方、届け方、頻度）
- 組み替えてはいけないもの: 師匠、教え子、掘る場所
- 差し戻す: 同じことをダラダラ繰り返しているのに手段を一切変えていない／逆に掘る場所ごと変えている（PR-148 の両側の逸脱）／繋がりが1つも報告されない状態が2ヶ月連続

**期報（2ヶ月） — 固定対象の見直し検査**
- 主目的: 固定してきた人・場所を再評価し、次の2ヶ月の1点を確定する
- 検査する問い: 決めた人を勝たせられたか（PR-151）／自分の発言は2ヶ月間一貫していたか（PR-146）／死に方・生き方から見て、この1点は一貫性の槍の上にあるか（PR-144）
- 差し戻す: 見直しの結果が「変えない」なのに理由が言語化されていない／固定対象を毎期変えている（固定になっていない）／やらないことが3項目未満

### 3-3. 総会月（4月・10月）をまたぐ期報の特例

全体総会は「これまでの整理を全て見直して配置し直す日」であり、通常の期報より見直しの範囲が広い（§6）。4月または10月を含む期報では、上記に加えて次を必須項目にする。

1. **整理**: 現在抱えている物・こと・予定を棚卸しし、やめるものを確定する
2. **コスト見直し**: 利益を作る／時間を浮かせるという観点で費用を再配置する（MS-085「残し方を考える」）
3. **再配置**: 5要素すべてを対象に配置し直す（この期に限り、人・場所も含めて全要素が見直し対象）

総会月を含まない期報でこの3点を要求しない。毎期やると「決めた人を固定する」が成立しなくなる。

## 4. ポジティブ事故ゲート（お金の判断・全期間共通）

新しい支出を伴う目標が出たら、この順で問い、上から順に成立する選択肢を採る（PR-149）。

1. **そもそもかけない** — お金をかけずに同じ結果へ届く手段はないか
2. **回収してから実行する** — 先に回収の当てを確定させてから支出できないか
3. **かけてから回収する** — これは最後の手段。採るなら回収条件と期限を目標に明記させる

「良さそうだから先に投資する」はポジティブ事故として扱い、`やらないこと` へ落とす。

## 5. 心の扱い（振り返り対話での適用・MS-082）

- 出力がうまくいかなかった期間でも、いちいち悲観・がっかりさせない。**傷つかないと決める**ことを前提に事実だけを扱う。
- 一つ一つの行動に大きく当てにしない。単発の失敗を目標設計の否定材料にしない。
- 反省の言語化ではなく、次に掘る場所の特定へ会話を戻す。
