【挑戦宣言と企画】

●目的ーあなたの事業や会社の目的は何か？
個人も組織も家庭すらも、富が右肩上がりに積み上がる世界を、全ての知人に届ける。

●目標ーその目的に近づくための数値的な目標
・個別相談 30件
・運営メンバーからの引き上げ 10件

●その目標を実現するための挑戦
100人のセミナーイベントを12月12日に開催する。
※ポイントー使える箱は定員数で意識の基準を落とさない
※ズームなら基本100人以上

●リスク回避方法
・健康が崩れない理由
生活リズムは崩さない。もともとスケジュールを少なくしていた所に入れたので、稼働量は変わらない。

・信頼が崩れない理由
信頼していただきたい方に声をかけた企画。今回参加できない方には「次回は必ず一緒に」と伝え、当日までのライブをコラボで一緒にお願いしている。

・家族が崩れない理由
家族との時間は削っていない。企画の内容も日程も、家族に全て話してある。

・社内拠点が崩れない理由
社内メンバーの成長が中心の企画。信頼は増えることはあっても下がらない設定にしている。メンバーのペースに合わせ、自分の基準とは連動させない。

・開催前にお金が全て回収できているor1円も費用がかからない理由
会場費はかかっていない。スポンサーのブース出展で100万円を回収済み。
有料運営メンバーは3万円×30人で90万円を入金済み。
VIP先行予約は5万円×10人で50万円を決済済み。
チケット販売前の時点で、100万円＋90万円＋50万円で240万円の利益が確定している。

●挑戦を必ず達成するために行うこと
1.100日で100名とコラボライブを行い、毎回セミナーを告知する
2.個別相談をセミナー開催前から受け付ける
3.YouTubeを毎日発信し、エンド画面・コメント欄・概要欄からセミナーへ案内する
4.小規模Zoomを3回開催し、当日のセミナーへ誘導する
5.小規模Zoomでも、開催前に個別相談を獲得する

上記行うことで必ず達成します。

●目標を追うために定期の報告はどのタイミングで行いますか？
週1回、月曜9時にLINEで集客数の経過を報告します。
