# D1 (SQL データベース)

## データベースの管理

```bash
# データベースを作成
pnpm wrangler d1 create my-database

# ロケーションを指定して作成
pnpm wrangler d1 create my-database --location wnam

# 一覧
pnpm wrangler d1 list

# 情報を取得
pnpm wrangler d1 info my-database

# 削除
pnpm wrangler d1 delete my-database
```

## SQL の実行

```bash
# SQL コマンドを実行 (リモート)
pnpm wrangler d1 execute my-database --remote --command "SELECT * FROM users"

# SQL ファイルを実行 (リモート)
pnpm wrangler d1 execute my-database --remote --file ./schema.sql

# ローカルで実行
pnpm wrangler d1 execute my-database --local --command "SELECT * FROM users"
```

`--remote` / `--local` の指定を忘れないこと。省略時の対象を取り違えると本番データを操作する事故につながる。

## マイグレーション

```bash
# マイグレーションを作成
pnpm wrangler d1 migrations create my-database create_users_table

# 未適用マイグレーションの一覧
pnpm wrangler d1 migrations list my-database --local

# ローカルへ適用
pnpm wrangler d1 migrations apply my-database --local

# リモートへ適用
pnpm wrangler d1 migrations apply my-database --remote
```

## エクスポート / バックアップ

```bash
# スキーマとデータをエクスポート
pnpm wrangler d1 export my-database --remote --output backup.sql

# スキーマのみエクスポート
pnpm wrangler d1 export my-database --remote --output schema.sql --no-data
```

## 設定バインディング

```jsonc
{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "my-database",
      "database_id": "<DATABASE_ID>",
      "migrations_dir": "./migrations"
    }
  ]
}
```
