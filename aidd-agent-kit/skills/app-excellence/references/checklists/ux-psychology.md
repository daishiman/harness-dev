# Checklist: UX心理学(適用と倫理ガード)

## A. 速度と負荷(★=Sサイズでも必須)

- [ ] ★ 全操作が0.4秒以内に何らかの反応を返す(Doherty閾値)
- [ ] ★ 1画面の主要アクションは1つ、選択肢は5以下(Hick)。超える場合は段階的開示
- [ ] ★ タップ領域44pt以上・主要操作は親指圏(Fitts)
- [ ] ★ 再入力を求めない(既知の情報は既定値に)/認識で選ばせる(recognition over recall)
- [ ] 賢い既定値が全選択項目に設定されている(default effect)
- [ ] 情報は3〜4塊に分割されている(chunking)

## B. 感情と記憶

- [ ] ★ ピーク体験とエンド体験がT2の指定どおり実装されている(peak-end)
- [ ] 進捗が見える(プログレス/残りステップ)。開始時点で少し進んでいる(endowed progress)
- [ ] 中断しても続きから再開できる(Zeigarnik対応の自動保存)
- [ ] 不安の除去: 可逆性の明示(「あとで変更できます」)・待ち時間の理由表示
- [ ] 成果の可視化: ユーザーの行動がもたらした価値を数値で返す(「今月20時間節約」)

## C. 倫理ガード — ダークパターン禁止リスト(1つでも該当したらリリース不可)

- [ ] ★ confirmshaming なし(拒否ボタンに罪悪感を持たせる文言)
- [ ] ★ 偽の緊急性・偽の希少性なし(実在しないカウントダウン・残りわずか表示)
- [ ] ★ 解約・削除・オフが、登録・オンと同等以下の手数でできる(roach motel禁止)
- [ ] ★ 事前チェック済みのオプトイン(メール購読等)なし
- [ ] 誤クリックを誘うレイアウトなし(広告位置・すり替えボタン)
- [ ] 通知・バッジで強迫しない(既定は控えめ、ユーザーが制御できる)
- [ ] 比較を妨げる価格・条件表示なし(景表法・特商法の観点でも確認)
