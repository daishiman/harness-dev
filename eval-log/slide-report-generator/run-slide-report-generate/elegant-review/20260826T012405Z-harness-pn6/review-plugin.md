## 改善

- 177原則を媒体中立の構造化カタログへ抽象化し、正本を1つに限定した。
- guide側は原則・selector・tool adapterをgenerated byte mirror、consumer bindingだけをlocal overlayとした。
- promptの反復規約をconsumer bootstrapへ集約し、各promptはexact markerと固有指示だけを持つ。
- selectorはconsumer別に必要十分な原則を選び、selected/xrefを別予算で返すselection envelopeを提供する。
- PowerPoint、Google Slides、HTMLは同じ原則と選択結果を共有し、製品差分だけをadapterへ分離した。
- versioned schema、fail-closed validator、vendor parity、177原則分類、全対象agent scope、guide overlay deliveryを通常実行で検査する。

独立approverの初回監査で `slide-renderer` と `ai-image-diagram-producer` の未分類を検出した。AI画像担当はconsumerへ接続し、判断を行わない決定論rendererは理由と実在evidenceを持つ明示除外とした。P36がこの排他的閉包を継続検査する。
