# 標準デザインの再現性改善

対象は `plugins/system-briefing-book` の既定デザイン、ボード生成、まとめHTML、配色更新、関連仕様。思考リセット後、9＋9＋12の3エージェントで30種すべてを適用した。分析完了後に独立ファイルを並列修正し、2回の改善・再検証で4条件を満たした。

| 条件 | 最終判定 | 確認した内容 |
| --- | --- | --- |
| 矛盾なし | PASS | 配色設定と更新後CSSが一致。共通トークンと配置の責務を文書・実装で統一 |
| 漏れなし | PASS | 必須役割・空値・参照切れ・循環・CSS優先順位を検査。標準／独自配色を実ブラウザ確認 |
| 整合性あり | PASS | ボードとまとめが同じ色・フォントを参照。別配色のフォールバックを除去 |
| 依存関係整合 | PASS | 正本→案件CSS→ボード→まとめの経路、再生成、出典との開発時照合を確認 |

## 変更

- **既定デザインを一つの契約へ集約**：`references/design-contract.md` に同梱のオリジナル標準デザイン、正本、部品、7種の雛形、生成・再生成の責務を記載。入口スキルと各工程から参照する。値やCSSを文書に複製しない。根拠：抽象化・MECE・メタ・論点・KJ法。
- **二重定義を削減**：まとめHTMLの24個の `--book-*` 別名と旧色フォールバックを削除し、色・文字・影を既存の役割トークンから直接参照。値が同じボタン・カードの角丸も既存トークンへ接続した。ボードの配置や業務内容は維持。根拠：要素分解・水平・トレードオン・改善。
- **配色更新の不整合を修正**：既存案件の `palette` を優先。設定と異なるCLI指定は書込み前に拒否する。設定内の相対パスは資料フォルダ基準。原本が移動した配布済み資料も、更新不要の再実行では既存CSSを保持する。根拠：演繹・帰納・プロセス・システム・因果分析。
- **配色の検査を共通化**：必須役割を標準CSSから取得し、scaffold・render・bookで共有。不足・空値・参照切れ・循環を止め、不正CSSで既存HTMLやPNGを上書きしない。対応形式はコメントとトップレベルの `:root` 宣言。CSS全般の構文検査ではない。根拠：批判・垂直・if・仮説・因果ループ。
- **名称と出典を整理**：開始時点で現行プラグイン・同梱キット・確認した導入先スキルに旧配色名の該当なし。不要な名称を新設せず、利用者向けは「標準デザイン」へ統一。再混入検査を追加した。正確な著作権・ライセンスとフォント名 `Hiragino` は保持。根拠：素人・価値提案・戦略・ダブルループ。

全30種の個別観察と証拠は [初期分析](findings-initial.json)、修正後の対応は [最終分析](findings.json) に保存している。残りの方法も省略せず、3エージェントの原本レポートを保存した。
