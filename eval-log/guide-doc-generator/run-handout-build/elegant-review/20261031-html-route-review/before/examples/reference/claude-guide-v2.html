チャットでできそうなら、
チャットでやる。

チャットは体力(トークン)の消費が少ない。Coworkは働き者のぶん、たくさん食べます。

チャット向き — 1対1のやりとり
  • ファイル1つを渡して分析・要約
  • 議事録・メール・説明文をつくる
  • 「どう進める?」の壁打ち・たたき台
  • その場で答えがほしい調べもの
Cowork向き — 丸ごと委託・自動化
  • フォルダごと・複数ファイルの処理
  • 集計→グラフ→資料まで通しの作業
  • 毎週・毎月のくり返し作業
  • 時間のかかる作業(閉じても動く)

チャットでやってみよう3つ中 0クリア

① 自分のExcel・CSVを投げて「分析して」
普段の実データでOK。誰向けか・何を知りたいかを添えると精度が上がる
② 関数・条件付き書式入りのExcelを作らせる
「赤字の行は赤くして」「合計は自動計算で」まで組み込み済みで出てくる
③ 上司に見せる形に仕上げる
分析結果を報告資料に。さっきのマップから形をえらんで指定してみる
実データを投げる 一発で完璧を狙わない 追加指示で直していく 迷ったらOpus・軽い作業はSonnet
分析をたのむ このExcelは月次の実績データです。車両別の推移と、赤字になっている要因を分析して、経営者に説明できる言葉でまとめてください。
Excelを作らせる 燃料費と走行距離を入力すると利益が自動計算されるExcelを作ってください。赤字の行は条件付き書式で赤くしてください。
資料に仕上げる この分析結果を、上司への報告用にA4で1枚のパワポにまとめてください。結論を最初に、数字は大きく見せてください。

Coworkのすごいところ

フォルダごと任せられる
中のファイルを自分で探して読んで、整理・書き込みまでやる
時間で勝手に動く
毎週・毎月のレポートをスケジュール設定して自動実行
操作を録画→覚える
普段のPC作業を見せると「スキル」として覚えて、次から自動でやる

コツ:「何を・どうやって・どんな形で」を最初に伝える。あとは他の仕事をしていてOK。

チャットとCowork、共通のしくみ

どちらで覚えても、両方で使えます。

コネクタ = 外とつながる
Notion・Kintone・カレンダーなどと接続。Claudeがアプリ同士をつなぐハブになる
スキル = やり方を覚える
仕事の手順・型をClaudeに覚えさせて、何度でも使い回す
