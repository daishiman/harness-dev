# 参考HTMLの分析と適用判断

対象は利用者指定の `2026-10-30_Claude-Codeサブエージェント-勉強会資料/handout.html`。
2026-10-31 にローカルのHTML/CSS/JavaScriptを読み、Chromeで表示して観察した。
素材の文面と画像は転載せず、情報設計と操作を抽出した。元のHTMLは更新していない。

## 観察した事実

- 13節のうち12節が本編、1節が付録。本文の画像15枚と表紙1枚、SVG図解8点、表9点、
  details/summaryのトグル15件を持つ。トグルは全件が初期状態で閉じていた。
- 広い画面は左の目次を固定し、現在地だけを濃くする。狭い画面は上帯へ切り替える。
- 節は番号と見出し、場面の挿絵、短い主張、比較表やカード、判断軸の順で読める。
- 背景は淡い青、紙面は白、文字は濃い紺。青の濃淡と罫線で階層を示している。
- トグルは丸い矢印マークが回転し、開くと区切り線が出る。答えの詳細を後から読める。
  印刷直前に閉じていたトグルを開き、終了後に元へ戻す。
- 1440px表示で図解の幅は880px、viewBoxは860px。最小の注釈文字は12.5pxで、
  全図が `max-width:100%` で縮むため狭い画面では文字も縮む構造だった。
- 8図のうち5図はflow、2図はversus、1図はhierarchy。図種の偏りがある。

## 適用した判断

| 観察 | 今回の反映先と判断 |
| --- | --- |
| 図・カード・表を文章の前で読める | 既存の節順を保ち、説明位置で図へ置き換える。図だけを先頭へ集めない |
| 挿絵と構造図が同じ節にある | 「図解は個別指定まで保留」を撤回。先頭の挿絵と説明図の担当情報を分ける |
| 図種がflowに偏る | 原文の関係を抽出して候補を比較し、単なる選択肢へ順序の矢印を付けない |
| テーマに統一された色 | 新しい図にも既存の文字・主題・補助・表面・罫線の変数を使う |
| 詳細の段階的開示 | 既存B10へ開閉マーク・フォーカス・行分割と印刷時の状態復元を反映 |
| 図の文字が縮む | 実表示文字の下限から図の幅を導き、図内スクロールと拡大を設ける |
| 関係の厳密さが必要な説明 | 接続先・方向・条件・数値を検証し、専用表記が必要なら事前描画して取り込む |

参考HTMLの見た目をそのまま全資料へ固定しない。構成データ・テーマ・候補集・
意味判断・決定論描画を分けることで、別の題材や新しい図にも対応する。
数値の閾値と実行規則は `config/handout-visual-policy.json`、表現の入力例は
`config/handout-diagrams.json` へ一本化した。
