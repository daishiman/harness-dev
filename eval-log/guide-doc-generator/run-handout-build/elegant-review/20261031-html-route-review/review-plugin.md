# 図解選定とHTML表現の再検証

30種類すべてを使用し、3担当による独立並列分析後に改善した。別の担当による再検証で追加退行を検出し、2周目で解消した。成果物の削除は行っていない。

## 確認した結論

- 候補一覧だけで、全ての文章・図の意味保持や可読性は保証できない。関係の抽出、媒体の選択、描画への接続、実表示の確認を分ける。
- HTMLは図種ではなく出力・描画方法。利用者が毎回指定する必要はない。短い手順・カード・比較・単一KPIはHTML/CSS、接続・座標を読む図はSVG、厳密な専用表記は作図済み素材を選べる。
- 画面の文字が14px以上でも、核心の数値が画面外なら読めるとはいえない。375pxでKPIが見えない反例を修正した。

## 表示と回帰検証

- 1440/768/375pxで確認。375pxのKPIは数字37.5px・単位20px・説明16pxで見える。
- 候補表は関係列約38px→112px、375px時の高さは約4,977px→約3,685px。表の各列は表示領域内で読み切れる幅を保つ。
- ページ全体の横はみ出しと実例リンク切れは0。専用図表は1200px幅のSVGで原寸と拡大操作を確認。
- 全体回帰は3,581件成功・13件スキップ・3,141サブテスト成功。説明の追加修正後は関連1,003件と168サブテストが成功。
- 独立した担当が、説明の欠落/改変の拒否とChromeアクセシビリティツリーへの接続を確認した。

## 判定の範囲

PASSは今回の変更・12所見・標準例・接続契約を対象とする。任意の元画像、任意の資料の意味保持、すべての印刷版面、環境に作図ツールが存在することを保証しない。利用不能・意味保持不能・実表示未確認を未達として残す経路を備えた。

証跡: `findings.json`、`verdict.json`、`independent-review-round1.json`、`independent-review-round2.json`、`validation-summary.json`。初期所見と改善前のバイト列も同じ作業域へ保持している。
