# guide-doc-generator で配布用の資料を1本作れるようになる

- **種別**: onboarding (導入ガイド)
- **日付**: 2026-08-18
- **想定読者**: 資料は日常的に作るが、HTML やコマンド操作は触ったことがない担当者
- **所要**: 45分 / 6 セクション / 9 部品
- **適用プリセット**: `onboarding` (提示順 `demo_first`・到達目標 `operable`)

## 同梱物

| ファイル | これは何か | どう使うか |
|---|---|---|
| `handout.html` | 配布するのはこれ 1 つ。画像も含めて 1 ファイルに収まっている | そのまま相手へ渡す。ブラウザで開くだけで読める (通信不要・A4 印刷可) |
| `handout-config.json` | この資料の正本。何をどの順で載せるかを書いた設計メモ | 内容を直すときはこちらを直して作り直す。HTML を直接書き換えない |
| `assets/` | 素材の原本置き場 (本資料は画像なしのため空) | 画像を足すときはここへ置き、構成データから参照する |
| `.handout-route.json` | どこへ・どの規則で出力したかの記録 | 再出力や差し替えのときに出力先を突き合わせる |

## 作り直しかた

```bash
python3 <plugin>/scripts/render-handout.py --config handout-config.json --out handout.html
```

起動引数を足さなくても、この構成データだけで**同じバイト列の HTML**が出ます (テーマなどの採用値は構成データへ書き戻し済み)。
