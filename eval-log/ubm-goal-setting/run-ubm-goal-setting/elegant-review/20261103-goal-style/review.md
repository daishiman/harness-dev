# 目標設定プラグインの30思考法レビュー

対象：`plugins/ubm-goal-setting` の今回変更。月間・3ヶ月・年間の目標設計を、売上→成果→行動の逆算と、短い「何をする＋期日」で統一する。個別案件の人数・金額は固定しない。

## 実施順序

1. 思考リセット・俯瞰：`fresh_overview` が読み取り専用で確認。既存成果物は保持。月報だけに例外を足す先行案を前提にせず再検討した。
2. 並列分析：同担当が論理・構造9種、`meta_review` がメタ・発想9種、`system_review` がシステム・戦略・問題解決12種を担当。3担当の全分析完了後に実装を開始した。
3. 改善：`docs_refactor` が正本と対話・整形指示、`validator_fix` が検証コードと回帰テストを担当。親がローカル方針・配布・統合検証を担当する。
4. 再検証：変更後のテストと、実装担当とは別の担当による4条件レビューで判定する。最大3回、未解消をPASSへ変更しない。

## 30種の適用結果と改善根拠

| 思考法 | 確認した問題・維持する点 | 改善方針 |
|---|---|---|
| 批判的思考 | 月報だけの例外は最新の期・年共通要望を満たさない | 長期3層の共通規則へ統合 |
| 演繹思考 | 売上直結のみという条件は面談等の中間成果と矛盾 | 直接成果と中間成果を区別 |
| 帰納的思考 | 項目省略・片側修正漏れが繰り返された | 案件値でなく対応関係を検証 |
| アブダクション | 指示不足より競合する指示が誤出力の原因と考えられる | 既存正本の該当規則を直接修正 |
| 垂直思考 | 単発除外の規則が承認済み総売上と衝突 | 計上基準を継承し継続・単発を区分 |
| 要素分解 | 数字の集合比較が数量と期日の役割を消す | 期日と数量・単位を分離 |
| MECE | 成果の3列対応だけでは行動の脱落を見逃す | 成果と行動に同じ対応検査を適用 |
| 2軸思考 | 期間と三層の分類に月報だけの規則が混在 | 共通定義と月報固有同期を分離 |
| プロセス思考 | 売上→成果→行動の順は正しいが既知回答の再質問がある | 未確定事項だけを聞く |
| メタ思考 | R4の実行範囲外の追記だけでは旧指示を消せない | 実行テンプレートそのものを修正 |
| 抽象化思考 | 期間が異なっても設計順序と短い書き方は共通 | 表記と逆算を一箇所へ集約 |
| ダブル・ループ思考 | 件数制限が必要な項目を削る誘因になる | 長期3層は件数を推奨へ |
| ブレインストーミング | 別スキルや期間別例外は保守箇所を増やす | 既存正本の共通化を選択 |
| 水平思考 | 正本・対話・整形への規則複写が更新漏れを生む | 各担当は固有の問いと参照に絞る |
| 逆説思考 | 項目を減らす簡潔化が比較可能性を壊す | 項目を残し説明を削る |
| 類推思考 | 提出・管理は同じ計画の表示違い | 項目・数値・期限を同期 |
| if思考 | 人数と月を交換しても数値集合は一致する | 役割別比較の反例テストを追加 |
| 素人思考 | 面談が売上を確約する表現と背景注記は誤解を生む | 中間成果の位置を明示し本文を短く |
| システム思考 | 局所例外が収集・対話・整形・検証へ波及する | 共通正本と呼出側を揃える |
| 因果関係分析 | 面談・紹介は受注の先行成果であり売上そのものではない | 支える先を示し売上を二重加算しない |
| 因果ループ | 行動実績の項目欠落が振り返りを切断する | 目標・実績・差分を同項目同順に |
| トレードオン思考 | 件数削減か長い注記という二択は不要 | 主要行動の動作と期日だけ残す |
| プラスサム思考 | 同じ行動の重複記載は双方の更新負担になる | 主成果へ配置し必要な対応だけ示す |
| 価値提案思考 | 誤った一致判定は利用者の安心を損なう | 検査範囲と意味レビューの限界を明示 |
| 戦略的思考 | 固定の単発除外は当人の売上戦略を変えてしまう | ユーザー合意の計上範囲を維持 |
| why思考 | 混在→定義分散→例外衝突→追記増加→適用順の曖昧さ | 追記を増やさず競合する定義を整理 |
| 改善思考 | 文字数の目安という文言とFAILが不一致 | 仕様と検査強度を揃える |
| 仮説思考 | 項目名と数字だけで同期できる仮説に反例がある | 数量・単位・期日と欠落の回帰テスト |
| 論点思考 | 本質はフラグ追加ではなく売上からの逆算設計 | 共通設計を先に修正 |
| KJ法 | 問題は設計・表現・履歴・検証配布の4群 | 各責務の正本へ整理 |

30種すべて適用済み。省略0。初期分析の4条件は、矛盾・漏れ・整合性が要改善、依存関係は実装・配布検証待ちだった。
