# 四層目標の一貫性と軌道修正

対象：UBM目標設定プラグインの追加要件。既存の規則・対話・整形・レビュー・検証を置換し、月報等の目標本文は変更しない。

## 採用した方針

- 年間→3ヶ月→1ヶ月→1週間の順に、直属上位のどの成果をその期間にどこまで進めるかを対応付ける。各層内は売上→成果→行動の順で逆算する。
- 年間の最終到達点と月・週の実行値を分ける。月・週は前回目標と実績差分に応じ、数量・行動・期限・配分を見直せる。
- 上位の最終到達点や過去目標・実績・差分を自動で書き換えない。修正時だけ、管理用に変更と理由・上位への影響を短く残す。
- 同値継承する年/期の参照文脈は厳格に維持。月の4内訳は管理用の見直し記録と実際の上位配分・月実行値・週の月額参照を照合する。
- 基準配分と実行目標を混ぜず、週間を毎週一律の日割りへ固定しない。記録の完全性・値の対応は機械検査、理由と上位到達見通しの妥当性は意味レビューで確認する。

## 独立再検証

文書担当は `docs_refactor`、コード担当は `validator_fix`。別担当 `fresh_overview` が文書・実caller、`system_review` がコードと反例を検証した。

1周目で月報テンプレートの無条件同値を検出し、既存注記を置換した。コードの独立反例では、コメントやコードフェンスで節全体を囲んだ場合に古い記録が有効になる問題を検出し、可視本文の解析へ置換する修正を依頼した。
