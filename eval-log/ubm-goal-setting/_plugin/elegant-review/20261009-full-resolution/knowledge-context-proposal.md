# UBMナレッジ背景の評価契約を整合する提案（未適用）

独立評価で、L0 KL-002は全entryのbackgroundに「業種・規模・状況のうち2つ以上」を求める一方、UBMのknowledge/schema.jsonは「固有業種・特定数値は含めず、構造的な状況」と定義していることが判明した。原文に業種・規模が無い普遍的な指針へ値を捏造して、この差を埋めてはならない。

提案はL0を変更せず、UBMのL1評価契約だけに次の背景品質判定を追加する。

- レベル1（不可）: 適用状況が曖昧、理由・制約が不明、または原文に無い事実を補っている。
- レベル2（可）: 原文にある適用状況と、判断が必要になる理由・制約・失敗条件を具体に記述する。抽象的な一文だけでは合格しない。業種・規模を指定する実例は、その情報も原文通り保持する。
- レベル3（優）: 原文にある場合は、比較する条件、施策、結果、適用限界までたどれる。

不足する背景は、同じentryの原文rationale/root_cause等を根拠に増補し、旧background・採用元field・SHAを移行証拠に残す。根拠が無いentryは不合格のままにする。元の内容・出所・件数を削除しない。

例: AG-183の「信頼と依存が混同されている。」には、同entryの原文rationale「当てにした一本が倒れると、計画ごと止まる。」を補う。業種や人数は追加しない。これにより適用状況と失敗条件を確認できる。

この変更は単なる表記修正ではなく意味上の評価契約変更のため、適用前にユーザー承認が必要。代替は、現在の評価基準を維持し、元資料から実在する業種・規模を確認して背景を補う。元資料にも無ければそのentryは現基準でFAILのままにする。
